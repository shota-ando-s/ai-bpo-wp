退職者対応は、人事・情シス・現場が関わるうえに作業項目が多く、「アカウントを止め忘れた」「保険手続きが漏れた」といったミスが起きがちです。本記事では、**オフボーディングチェックリスト**を4領域・時系列のテンプレート形式で整理しました。そのままコピーして自社の退職者対応に使える、会社側のやることリストです。

> 本記事は [オフボーディングとは？意味・進め方の完全解説](/offboarding-complete-guide/) のテーマをさらに掘り下げた関連記事です。
> まずは全体の流れを知りたいという方は、ぜひメインの記事からご覧ください。

## オフボーディングチェックリストとは

**オフボーディングチェックリストとは、従業員の退職時に企業側が行うべき手続き・引き継ぎ・IT資産回収・関係維持の作業項目を、抜け漏れなく実行するための一覧表のことです。**

退職者対応は、大きく4つの領域に分かれます。

1. **人事・労務手続き**（社会保険・雇用保険・税務・書類）
2. **IT・情報セキュリティ**（アカウント停止・機器回収）
3. **業務引き継ぎ・ナレッジ移転**（マニュアル化・後任への移管）
4. **関係維持・エンゲージメント**（退職面談・アルムナイ登録）

この4領域を「退職決定後 → 退職日直前 → 退職日当日 → 退職後」の時系列で並べると、いつ何をやるべきかが明確になります。

---

## 【時系列】オフボーディング全体スケジュール

| タイミング | 主なアクション |
|---|---|
| 退職決定後（1〜2ヶ月前） | 退職届受理・スケジュール確定・後任決定・引き継ぎ計画立案 |
| 退職日2〜4週間前 | 引き継ぎ実施・退職面談・社内外への周知準備 |
| 退職日直前〜当日 | IT資産回収・アカウント停止・貸与物回収・最終手続き |
| 退職後 | 保険・税務の事後手続き・書類交付・アルムナイ登録 |

以下、領域別のチェックリストを示します。

---

## 1. 人事・労務手続きチェックリスト

法令で期限が定められた手続きが多く、漏れると行政上のトラブルになります。

- [ ] 退職届・退職願の受理と保管
- [ ] 退職日・有給休暇消化スケジュールの確定
- [ ] 健康保険・厚生年金の資格喪失手続き（資格喪失日＝退職日の翌日から5日以内）
- [ ] 雇用保険の資格喪失手続き・離職票の発行（離職日の翌日から10日以内）
- [ ] 住民税の手続き（特別徴収から普通徴収への切替など）
- [ ] 源泉徴収票の作成・交付
- [ ] 退職金の計算・支給手続き（制度がある場合）
- [ ] 健康保険証の回収
- [ ] 各種証明書（離職票・退職証明書等）の準備・交付

手続きの期限は、健康保険・厚生年金が日本年金機構の[従業員が退職・死亡したとき（健康保険・厚生年金保険の資格喪失）の手続き](https://www.nenkin.go.jp/service/kounen/tekiyo/hihokensha1/20150407-02.html)、雇用保険がハローワークの案内（[ハローワーク川崎](https://jsite.mhlw.go.jp/kanagawa-hellowork/list/hw-kawasaki_00087.html)）で確認できます。詳しい手続きの期限や必要書類は [退職手続き 会社側のやること完全ガイド](/employer-resignation-procedures/) で解説しています。

---

## 2. IT・情報セキュリティチェックリスト

1つでもアカウントが残ると情報漏洩リスクになります。停止のタイミング設計が重要です。

- [ ] PC・スマートフォン・タブレットなど貸与端末の回収
- [ ] メールアカウントの停止・転送設定
- [ ] 社内システム・基幹システムのアカウント無効化
- [ ] クラウドストレージ（Google Drive・OneDrive等）の権限剥奪
- [ ] SaaS・各種Webサービスのアカウント停止（棚卸しが必須）
- [ ] VPN・リモートアクセス権限の無効化
- [ ] 共有アカウント・共有パスワードの変更
- [ ] 入館証・社員証・物理キーの回収
- [ ] データの引き継ぎ・私物データの削除確認

アカウント削除の具体的な手順は [ITオフボーディングの手順](/it-offboarding/)、SaaSの棚卸しは [退職者のIT資産回収・SaaS棚卸し](/offboarding-it-assets/) を参照してください。退職者によるリスク全般は [退職者のセキュリティリスクと対策](/offboarding-security-risks/) で詳しく解説しています。

---

## 3. 業務引き継ぎ・ナレッジ移転チェックリスト

最も手間がかかり、後回しにされがちな領域です。早期着手が成功の鍵です。

- [ ] 退職者の担当業務の棚卸し・可視化
- [ ] 後任者の決定（社内異動・新規採用・外部委託）
- [ ] 引き継ぎマニュアル・業務フロー図の作成
- [ ] 取引先・関係者リストと連絡先の整理
- [ ] 進行中の案件・タスクの状況整理
- [ ] 引き継ぎ期間中のOJT・同行
- [ ] 引き継ぎ完了の確認・残課題の洗い出し

引き継ぎの進め方は [業務引き継ぎの進め方](/handover-process/)、マニュアルの作り方は [引き継ぎマニュアルの作り方](/how-to-create-handover-manual/) で具体的に解説しています。属人化が深刻な場合は [業務の属人化を解消する方法](/knowledge-sharing-guide/) も参考になります。

---

## 4. 関係維持・エンゲージメントチェックリスト

退職を「終わり」にせず、組織改善と将来の再接点につなげる領域です。

- [ ] 退職面談（エグジットインタビュー）の実施
- [ ] 退職理由・改善提案のヒアリングと社内共有
- [ ] 社内への退職告知（適切な範囲とタイミング）
- [ ] 送別の場の設定（任意）
- [ ] アルムナイネットワークへの登録案内
- [ ] 退職後の連絡先・再雇用の意向確認

退職面談の質問例は [エグジットインタビューのやり方](/exit-interview-questions/)、退職者の再活用は [アルムナイ採用とは](/alumni-recruiting/) で解説しています。

## チェックリストを使う際の3つのポイント

オフボーディングチェックリストを形骸化させないために、次の3点を押さえましょう。

1. **担当者を明記する**：各項目に「人事／情シス／現場」など担当を割り当て、誰がやるかを曖昧にしない
2. **期限を入れる**：法定手続きには明確な期限があるため、時系列に沿って締切を設定する
3. **テンプレート化して再利用する**：退職のたびにゼロから作らず、自社版のテンプレートとして蓄積・改善する

専任の人事・情シスがいない中小企業では、これらの作業を内製しきれないことも多くあります。その場合は、引き継ぎ業務の文書化やマニュアル作成をAI・外部委託で効率化する方法もあります。

## よくある質問（FAQ）

### オフボーディングチェックリストに最低限入れるべき項目は？

「社会保険・雇用保険の資格喪失手続き」「貸与端末・入館証の回収」「全アカウントの停止」「業務引き継ぎ」「退職面談」の5つは最低限必須です。特にアカウント停止の漏れは情報漏洩に直結するため、SaaSを含めて棚卸ししたうえで網羅的にチェックします。

### 退職者のアカウントはいつ停止すべきですか？

業務引き継ぎが完了し、退職日を迎えるタイミングでの停止が基本です。早すぎると引き継ぎに支障が出て、遅すぎると情報漏洩リスクが残ります。停止日を事前に計画し、退職日当日に確実に実行できるよう情シスと連携することが重要です。

### チェックリストの担当部署はどう分ければよいですか？

一般的に、人事・労務手続きは人事部、アカウント停止やIT資産回収は情シス、業務引き継ぎは現場部署、退職面談は人事または上長が担当します。中小企業で専任者がいない場合は、各項目に担当者名を割り当てて抜け漏れを防ぎます。

### 退職者が貸与物を返却しない場合はどうすればよいですか？

まず返却期限と返却方法を書面やメールで具体的に伝え、郵送での返却も受け付けます。返却対象と期限は入社時や退職届受理時に一覧で示しておくと、トラブルを防げます。応じない場合は、就業規則や誓約書の定めに沿って対応し、必要に応じて専門家に相談します。

### 退職手続きの法定期限はありますか？

あります。健康保険・厚生年金の資格喪失届は資格喪失日（退職日の翌日）から5日以内、雇用保険の資格喪失届は離職日の翌日から10日以内に提出します。詳細は [退職手続き 会社側のやることガイド](/employer-resignation-procedures/) を確認してください。

## まとめ

- オフボーディングチェックリストは「人事・労務」「IT・セキュリティ」「業務引き継ぎ」「関係維持」の4領域で整理すると抜け漏れを防げます。
- 「退職決定後 → 退職日直前 → 当日 → 退職後」の時系列に各項目を並べ、担当者と期限を明記しましょう。
