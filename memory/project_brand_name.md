kantan-ai.jp のサービス名・ブランド名は「かんたんAI」。名前は次のように変わった。
- 「オフボード」→「ヒキツギAI」: 2026-10-14
- 「ヒキツギAI」→「かんたんAI」: 2026-11-08（ドメインの移行と同時。[[project-domain-migration]]）

2回とも、ユーザーの指示で全箇所を置き換えた。2026-11-08 の置き換え先:
- WordPress のデータベース全体（記事、タイトル、抜粋、Rank Math の設定、サイト名、お問い合わせフォーム）
- リポジトリの全ファイル
- ロゴ画像（images/kantan_logo.png、lp/logo-trim.png・lp/logo-hikitsugiai.png）。ヒラギノ角ゴ W7 で、「かんたん」は紺 #032A65、「AI」は青 #4B7DC2

キャッチの「休・退職者のAI引き継ぎ代行サービス」は変えていない。

**Why:** ブランド名をそろえるため。旧名が残ると、AI 検索や構造化データで別の組織と見なされる。

**How to apply:**
- 記事・タイトル・タグに「ヒキツギAI」「オフボード」を使わない。「引き継ぎ」「オフボーディング」は一般の言葉なので使ってよい。
- プラグインやコードの内部名（hikitsugi-*、HIKITSUGI_*）とページの URL のパスは、変えずに残している。
- サービス紹介の記事に、架空の事例・実績・提携を書かない。
  - Step1 の事例は「想定例」と明記してある。
  - 提携弁護士や「ベンダー20社のプロファイル」の記述は削除した。
  - 紹介料を受け取らないのは事実。
