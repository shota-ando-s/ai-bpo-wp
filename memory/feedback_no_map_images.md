地図を画像にするのはやめる（2026-10-17、ユーザー指示）。愛媛県の地域ページで post.py が H2 ごとに生成した画像に地図が入り、県・市町の形がおかしくなっていた。

**Why:** 画像生成AI（gpt-image-1）は実在の地形・行政区域の形を正確に描けない。地域ページで形の崩れた地図を出すと、その地域の読者に不正確・雑な印象を与え、信頼を落とす。

**How to apply:** 地図は絶対禁止（2026-10-18、ユーザーが改めて強く指示。プロンプトで禁止しただけでは秋田などでまだ地図が出た）。post.py の dalle_generate は ①strip_place_names で地名を消してからプロンプトに渡す ②has_map のビジョン判定で地図なら作り直す（最大3回） ③それでも地図なら画像を入れない。CLAUDE.md にもルールとして書いた。この仕組みを外さない。公開済みページに地図の画像が残っていたら `python3 scripts/fix_map_images.py [--apply] <記事.md...>` で、ビジョンモデルで判定して地図の画像だけ作り直す（作り直した画像も再判定し、地図ならそのまま残す）。ビジョン判定は薄い輪郭の地図を見落とすので、作り直した後は画像を一覧（コンタクトシート）にして目でも確かめる。「県内20市町の〜」のように見出しが地域そのものを指すと、禁止しても地図が描かれやすい。その場合は見出しを使わず「自治体の職員が生成AIを業務に使う様子」のような中立的な説明で作り直す。地図が必要なら、正確な地図データ（国土地理院など）を使うか、表やリストで地域を示す。初回投稿時のみ画像生成するルールは [[feedback-post-image-generation]] のとおり。関連: [[area-ai-media]]
