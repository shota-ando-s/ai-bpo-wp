hikitsugi.jp の地域ページ。県ページ `/area/miyagi/` の子として、市町村ごとに1ページ作る。
読者は、その市町村の中小企業の経営者・総務担当。狙う検索は「◯◯市 AI導入」「◯◯市 AI」。

> **2026-10-17 方針変更**：「◯◯市 AI導入」の検索上位は、市役所のAIの実証（スマートシティ、チャットボット共同実証など）の報道と国の資料が占め、中小企業向けに「自社で何ができるか」を答えるページがない。そこで、**自分の会社でAIを入れたい人をメインの読者**にし、「AIで何ができるか」と「近い業種の実際の事例」を前に出す。補助金は関心が高いので残すが、前面には出さず**中段**に置く。市役所の節では、生成AIだけでなく、**その市町村で過去に行われたAIの実証・事業**（報道・国の資料・実施企業の発表）も書く。
Google の AI Overview・AI モード・ChatGPT 検索に、段落単位で引用されることを狙う。

## 絶対に守ること

- **データファイルにない数値・事実を書かない。** 書きたい事実がデータにない場合は、WebSearch/WebFetch で一次情報（官公庁・自治体・公式サイト）を開いて確認できたときだけ書き、出典リンクを付ける。確認できなければ書かない。
- **架空の事例・実績・提携・顧客の声を書かない。** 試算は「当社試算」と明記し、前提を表で示す。
- **数値には、同じ文か直前の文に「時点」と「出典」を書く**（段落だけ抜き出されても正しいように）。表は直前の一文か表の下に出典と時点。
- 自治体名・制度名は正式名称。「市役所」「町役場」「村役場」を正しく使い分ける。
- 旧ブランド名「オフボード」は使わない。サービス名は「ヒキツギAI」、運営は「株式会社ふえん」（横浜市港北区）。「東京の会社」とは書かない。
- 今日は 2026年10月23日。補助金・事例・企業の確認日は「2026年10月23日時点」「2026年10月23日確認」。ファイル名の日付は 2026-10-23。
- 地名だけを差し替えたページにしない。市町村ごとの固有データ（人口、産業、生成AIの導入状況、補助金、地元企業、主要産業での試算）で中身を変える。他の市町村と同じ段落を使い回さない（「業務の引き継ぎにAIを使う」節も、その市町村のデータで書き出しを変える）。**自分の担当ページ同士でも段落を使い回さない。**
- **東日本大震災の復興は、AI・デジタル化に関係するものだけ**事実を書く。被害や復興の評価は書かない。
- **女川原子力発電所は、立地・施設名・事業者（東北電力）の事実だけ。** 評価は書かない。AIの事例として扱わない。経済センサスの電気業の従業者数を発電所の従業者数として書かない。

## 構成（H2 は次の順。見出しは検索クエリの形にする）

文字数の目安: **仙台市 9,000〜12,000字、他の市 6,000〜10,000字、町村 4,000〜6,000字**。無理に水増ししない。事例が見つからない節は短くてよい。人口の少ない町村（七ヶ宿町・大衡村・女川町・色麻町・大郷町・川崎町など）は4,000字前後でよい。同じ文章を使い回さない。

1. **リード（300字以内、H2なし）**: 一文目で「<市町村名>の会社がAIで何をできるか」を、その市町村の主要産業に即して言い切る（例:「名取市の食品工場では、多品種の製造実績の集計と分析からAIを入れると効果が出やすく、市内の水産加工会社が生成AIで分析レポートを数分で作る仕組みを報告しています。」）。続けて箇条書き3点: 主要産業でAIに任せやすい業務／市内・県内のAIの事例（実証・導入）／使える補助金（市独自の制度の有無を一言）。最後に補助金診断 `/shindan/` と県ページ `/area/miyagi/` へのリンク。
2. `## <市町村名>の会社はAIで何ができる？<主要産業>で効果が出やすい業務` — 経済センサスの業種構成、主要産業、有効求人倍率（ハローワーク名と時点）、生産年齢人口の2050年見込み（社人研、当社算出）を短く示し、業種ごとにAIで減らしやすい業務の表（3〜5行、列: 業種／AIに任せやすい業務／使うAIの種類〔生成AI・画像認識・予測など〕）。**仙台市はこの節で区の違い（区別の人口・2050年の減少率・区ごとの産業の特徴）を表か短い段落で示す**（stats.md の ipss と経済センサスの区の値。区の節・区のページは作らない）。
3. `## <市町村名>・<県名>のAI導入事例` — **実在の企業・自治体の事例だけ**。市町村内の企業の事例 → 県内の同じ業種の事例、の順。各事例は「企業名（所在地・業種）／時期／何の業務にどんなAIを使ったか／効果（数値は出典の文言どおり）」と出典リンク。市町村内に企業の事例がなければ「2026年10月23日の調査では、<市町村名>の企業がAIを導入した公開事例は見つかりませんでした」と書き、県内の事例に進む。市役所の実証はここではなくH2 7で書く（重複させない）。
4. `## <主要産業>のAI活用事例：他の地域の会社は何に使っている？` — 県外の、その市町村の**主要産業と同じか近い業種**の事例を2〜4件。地方の中小・中堅企業を優先し、大企業は1件まで。書き方はH2 3と同じ。最後に「<市町村名>の会社に当てはめると」として、どの業務から始めるとよいかを1段落で（当社の見方と明記）。
5. `## 試算：<市町村名>の<主要業種>（従業員<N>名）でAIを入れた場合` — 業種は wages.md にある業種から選ぶ（漁業・農業は毎月勤労統計に時給がないので、水産加工・食料品なら「製造業」、農協・集出荷・直売なら「卸売業・小売業」のように統計がある業種で試算し、その旨を前提表に書く）。主要業種はその市町村で従業者か出荷額が大きい業種を選ぶ（他の市町村と業種・規模・対象業務をできるだけ変える。末尾の表の「試算の業種の目安」）。対象業務は H2 3・4 の事例に近いものにする。前提表（対象業務／対象人数と業務量〔仮定〕／削減率25%〔Noy & Zhang 2023 の40%を割り引いた値〕／人件費時給〔wages.md の業種の時給×1.2〕）と結果表（月の削減時間／月の削減額〔年間〕／ヒキツギAI（AIチャット）月5万円〜／差し引き／初期費用50万円の回収期間）。**計算は python で確かめる。回収期間は 50万円÷（月の削減額−5万円）を小数1桁まで計算して「約◯か月」と丸める（例 5.5→約5か月半）。差し引きがマイナスや小さすぎる設定にしない。** 出典行（時給の統計、Noy & Zhang の PubMed リンク https://pubmed.ncbi.nlm.nih.gov/37440646/ 、仮定である旨）。

### 事例の書き方（H2 3・4・7 共通）

- **実在の企業・自治体・事業だけ**を書く。一次情報（企業・自治体の公式発表、官公庁・公的機関の資料、報道機関の記事）で確認し、出典リンクを付ける。AIベンダーの導入事例ページは、導入先の企業名と内容が明記されていれば使ってよい（「◯◯社（AIベンダー）の導入事例による」と書く）。
- 効果の数値は出典の文言どおりに書き、時期を添える。数値がなければ書かない。
- 事例の企業を評価・推薦する言葉は使わない。ヒキツギAI・ふえんが関わった事例のように読める書き方をしない。
- 他地域の事例は、その市町村の主要産業と同じか近い業種に限る（例: 亘理町はいちご→いちごの潅水のAI、登米市は肉用牛→牛の発情検知のAI、松島町は宿泊→旅館のAIチャット）。
- 同じ事例を複数の市町村ページで詳しく書かない。末尾の「事例の割り当て」で詳述と決めたページで詳しく書き、他のページでは1〜2文の要約と、そのページへのリンクにとどめる。
- **県の実証事業の事例**（先進的AI・IoT活用ビジネス創出実証事業・先進的デジタル技術実証事業）は「実証した」「試算した」と書き、「導入して削減した」と書かない。その後も業務で使い続けているかは確認されていない。
- **AIとほかの施策の効果が混ざる事例**（ホテル湖龍・霧島国際ホテル・つづく農園・樋口製作所・コマツ株式会社・プーラビダ・グラン・ファーム・ヤマザキライスなど。cases_outside.md の「AIの効果と他の効果が混ざるもの」）は、AIだけの効果と書かない。出典が分けている効果だけをAIの効果として書く。
- 市町村内に中小企業のAI事例がない場合は、そう明記したうえで、AI以外のDX事例（cases.md の「AIではないが市町村ページで使えるDX事例」）を、AIではないと分かるように短く紹介してよい。
- MLITなどURLに丸括弧を含むリンクは `%28` `%29` に置き換える（Markdownのリンクが途中で切れる）。
