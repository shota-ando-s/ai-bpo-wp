## 絶対に守ること

- **データファイルにない数値・事実を書かない。** 書きたい事実がデータにない場合は、WebFetch で一次情報（官公庁・自治体・公式サイト）を開いて確認できたときだけ書き、出典リンクを付ける。確認できなければ書かない。
- **架空の事例・実績・提携・顧客の声を書かない。** 試算は「当社試算」と明記し、前提を表で示す。
- **数値には、同じ文か直前の文に「時点」と「出典」を書く**（段落だけ抜き出されても正しいように）。表は直前の一文か表の下に出典と時点。
- 自治体名・制度名は正式名称。「市役所」「町役場」「村役場」を正しく使い分ける（飛島村・豊根村は村）。
- 旧ブランド名「オフボード」「ヒキツギAI」は使わない。サービス名は「かんたんAI」、運営は「株式会社ふえん」（横浜市港北区）。**「東京の会社」「名古屋の会社」とは書かない**。
- 今日は 2026年11月11日。補助金・事例・企業の確認日は「2026年11月11日時点」「2026年11月11日確認」（11月11日に確かめていない値は、データファイルの確認日のまま書く）。ファイル名の日付は 2026-11-11。
- 地名だけを差し替えたページにしない。市町村ごとの固有データ（人口、産業、生成AIの導入状況、補助金、地元企業、主要産業での試算）で中身を変える。他の市町村と同じ段落を使い回さない（「業務の引き継ぎにAIを使う」節も、その市町村のデータで書き出しを変える）。**自分の担当ページ同士でも、書き終わったほかの担当のページとも段落を使い回さない。国の制度の表・相談先の表・試算の説明・FAQの回答も書き分ける。** とくに同じ地域区分の近い市町村（海部の市町村、知多半島の町、西三河の自動車部品の市、奥三河の町村など）、同じ業種の試算のページは組み立てから変える。
- **県の事業を市町村の施策と書かない**（末尾の【D3】の一覧。あいち産業振興機構・あいち産業科学技術総合センター・愛知県よろず支援拠点・県の補助金・県のDX支援事業・STATION Ai〔県の事業として整備、運営は民間の STATION Ai株式会社〕は県・県域の事業・機関）。**県庁・大企業の話と、中小企業が使える支援（研修・補助・相談）を分けて書く。**
- **大企業・系列の工場（完成車・自動車部品の大手・鉄鋼・電機・航空・石油など）の話は、統計の値と会社名なしの1〜2文にとどめ（会社名は【D1】【D5】が公式で確かめた社名だけ）、試算・業務の表・事例は中小企業の業種で書く**（【D1】）。「企業城下町」「トヨタの町」「◯◯の町」と書かない。統計の値を特定の会社の値と読める書き方をしない。
- **ベンダーが「AI」と呼ぶシフト作成・配車・オンデマンド交通・電話応答のサービスは、中身を書き添える**。生成AIと混同しない。**資料にAIの記述がないデマンド交通（チョイソコせとあさひ・チョイソコとうかい・チョイソコこうたなど）・自動運転バス（豊田市・岡崎市）はAIの事例にしない**（【D3】）。
- **災害（2026年9月の大雨、11月8日の地震、2000年の東海豪雨など）は、資料の事実と時点だけを書き、評価しない。** 応援・復興の言葉を書かない。AIの事例として扱わない。**11月8日の地震の震源の地名は書かない**（県の資料の中でも「静岡県西部」と「愛知県東部」で食い違う）。書き方は【D1】。
- **国の出先機関は中部経済産業局・東海財務局（愛知県は名古屋市の本局が担当）・愛知労働局・東海農政局（愛知県拠点）・中部運輸局（愛知運輸支局）。** 「関東経済産業局」「近畿経済産業局」「中国経済産業局」「九州経済産業局」「中部財務局」「名古屋財務事務所」「愛知財務事務所」「関東財務局」「近畿財務局」「名古屋労働局」「中部労働局」「中部農政局」「関東農政局」「近畿農政局」「東海運輸局」「近畿運輸局」と書かない（**他県の仕様から写すと残る。置き換え漏れに注意**）。中部経済産業局のサイト（chubu.meti.go.jp）はこのコンテナから開けない（403）ので記事でリンクしない。
- **愛知県知事は大村秀章（2011年2月から、4期目）。** 知事の名前は県ページで1回まで。
- **他府県の値（岐阜県・三重県・静岡県など）と並べない。** 「東海4県で最も低い」のような資料の順位は書いてよいが、他県の値は書かない。県の値と市町村の値を取り違えない（後継者不在率などを市町村の値と書かない）。
- **静岡・三重・京都・北海道のページ（/area/shizuoka/... など）へのリンクは張らない。共有メモで他府県に割り当てた事例は使わない**（data/area/_tokai/shared.md の「事例の割り当て」）。

## 構成（H2 は次の順。見出しは検索クエリの形にする）

文字数の目安: **名古屋市 10,000〜12,000字、豊田市・豊橋市・岡崎市・一宮市 8,000〜10,000字、ほかの市 6,000〜9,000字、町村 4,500〜7,000字**。無理に水増ししない。事例が見つからない節は短くてよい。同じ文章を使い回さない。

1. **リード（300字以内、H2なし）**: 一文目で「<市町村名>の会社がAIで何をできるか」を、その市町村の主要産業に即して言い切る。続けて箇条書き3点: 主要産業でAIに任せやすい業務／市町村内・県内のAIの事例（実証・導入）／使える補助金（市町村独自の制度の有無を一言）。最後に補助金診断 `/shindan/` と県ページ `/area/aichi/` へのリンク。
2. `## <市町村名>の会社はAIで何ができる？<主要産業>で効果が出やすい業務` — 経済センサスの業種構成、主要産業、有効求人倍率（**ハローワーク名と時点。管轄全体の値**。**ハローワーク別の原数値を使い、県全体の1.23倍と並べない**。書き方は【D1】の「愛知県の値」）、生産年齢人口の変化（令和7年国勢調査の15〜64歳の2020→2025年の増減）、名古屋市への通勤（尾張の市町。【D1】）を短く示し、大企業の工場がある市町村は、統計の値と会社名なしの1〜2文（【D1】の (A)）にとどめ、続けて中小企業の業種（【D1】の (B)）を書く。災害のあった市町村は【D1】の書き方で1文。業種ごとにAIで減らしやすい業務の表（3〜5行、列: 業種／AIに任せやすい業務／使うAIの種類〔生成AI・画像認識・予測など〕）。他府県の値と並べない。

4. `## <主要産業>のAI活用事例：他の地域の会社は何に使っている？` — 県外の、その市町村の**主要産業と同じか近い業種**の事例。**愛知県では本文に使える県外事例が1件（野嵩商会）だけ**（cases_outside.md）なので、【D2】の「事例の割り当て」の書き方に従い、ほかのページは「見つからなかった」と短く書く。最後に「<市町村名>の会社に当てはめると」として、どの業務から始めるとよいかを1段落で（当社の見方と明記）。

### 事例の書き方（H2 3・4・7 共通）

- **実在の企業・自治体・事業だけ**を書く。一次情報（企業・自治体の公式発表、官公庁・公的機関の資料、報道機関の記事）で確認し、出典リンクを付ける。AIベンダーの導入事例ページは、導入先の企業名と内容が明記されていれば使ってよい（「◯◯社（AIベンダー）の導入事例による」と書く）。
- 効果の数値は出典の文言どおりに書き、時期を添える。数値がなければ書かない。**実証・見込み・目標・理論値・試算・テスト段階・精度・受講者や職員の自己申告の数値は、そう書く**（【D2】の「事例ごとの数値の注意」）。
- 事例の企業を評価・推薦する言葉は使わない。かんたんAI・ふえんが関わった事例のように読める書き方をしない。
- 他地域の事例は、その市町村の主要産業と同じか近い業種に限る。
- 同じ事例を複数の市町村ページで詳しく書かない。【D2】の「事例の割り当て」で詳述と決めたページで詳しく書き、他のページでは1〜2文の要約と、そのページへのリンクにとどめる。**仕様が名指ししたページ以外では、他県で詳述した事例・企業に触れない。**
- **県・市の事業の成果報告・事例集の事例**（県の「デジタル技術導入モデル実証事業」成果報告書など）は掲載時点の紹介で、その後も使い続けているかは確かめていない。時点と出典を書く。開発・実証中のものを導入済みと書かない。研究・実証段階の精度を、導入の効果と書かない。
- **補助金の交付決定・採択一覧にだけ出る企業**（県の中小企業デジタル化・DX促進補助金の採択など）は「採択された」「交付が決まった」までにとどめ、効果や導入済みと書かない。
- **AIとほかの施策（RPA・クラウド・基幹システム・ロボット・自動化設備）の効果が混ざる事例**は、AIだけの効果と書かない。出典が分けている効果だけをAIの効果として書く。
- 市町村内に中小企業のAI事例がない場合は、そう明記したうえで、AI以外のDX事例を、AIではないと分かるように短く紹介してよい。
- URLに丸括弧を含むリンクは `%28` `%29` に置き換える（Markdownのリンクが途中で切れる）。
- 記事の出典リンクは**開けるものだけ**。**愛知県のサイト（www.pref.aichi.jp）と名古屋市以外の市町村のサイトは、このコンテナの curl では 302 のループ・403 になり、WebFetch でだけ開ける**ことが多い（check_article・extract_claims のリンク確認で ERROR になる。WebFetch で開けたものは残してよい。報告に書く）。中部経済産業局（chubu.meti.go.jp）・一宮商工会議所（owari.ne.jp の 403 に転送）・経産省の一部は開けないので使わない。

## 愛知県のデータの補足（必ず読む）

### データファイル（data/area/aichi/）

- 上の「必ず読むもの」4 のとおり。【二次情報】/ verified: false /【検索結果のみ】/【未照合】/ confidence: secondary は使わない（使うなら原典を開いて確認）

### Web検索

WebSearch は**担当ごとに合計2回まで、できれば0回**。データにない事実を足したいときは、データにある公式URLか確実に分かっている公式URLを WebFetch か curl（ヘッダーを偽らない）で開き、確認できたときだけ書く。県外の事例を足すときは、使う前に `grep -rl "<社名>" articles/ data/` で他県の使用を確かめる。**仕様の「見つからない」「確認できなかった」は、執筆担当が一次資料を開いて違えば直してよい**。直したときは報告に書く。

- 県・市町村のサイトは、このコンテナの curl で 302 のループ・403 になることが多い（名古屋市は curl で開ける）。WebFetch では開けることが多い。WebFetch は要約を返すので、数値は PDF を curl で保存して pdftotext で確かめる（curl で取れなければ WebFetch の要約の値と分かるように扱う）
- **このセッションで開けなかったサイト**（調査の時点）: 中部経済産業局（403）、経産省の一部（DXセレクションのページなど）、一宮商工会議所（403 に転送）、社人研。開けないページは使わない。執筆担当が開けたら確かめて足してよい
