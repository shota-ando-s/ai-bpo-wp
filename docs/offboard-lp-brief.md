# Offboard LP 制作指示書（ai-bpo-wp の Claude Code 向け）

この文書は `allsrc/ai-bpo-wp` で作業する Claude Code にそのまま渡す指示書。AI-BPOプロジェクトの決定ログを知らない前提で、必要なコピー・仕様をすべて埋め込んである。

---

## 0. ゴール

`hikitsugi.jp` のフロントページを、**「Offboard（オフボード）」= 退職・休職する社員の業務をAIで引き継ぐ代行サービス**のLPに作り替える。

- 対象ファイル：**`themes/generatepress-child/front-page.php`**（既存LPを置き換え／作り替え）。CSSは同テーマの既存 `.lp-*` デザインシステムを再利用し、必要分を `front-page.php` 内 `<style>` か `style.css` に追記
- 既存のネイビー(#0d1b4b)×ブルー(#1a56db)基調は維持（Offboardのブランドカラーと一致）
- レスポンシブ必須・GeneratePressのレイアウトを壊さない
- 作業後 `./deploy.sh` でデプロイ

## 1. ブランド・トーン

- サービス名：**Offboard（オフボード）**　／　運営会社：**ふえん（fuenn.co.jp）** をフッター等に明示
- ポジショニング一行：**「人が辞めても、業務はここが引き取る。」**
- トーン：**見出しはストレートに不安を突く／本文はやわらかく伴走**（安心感）。中小企業の経営者・管理部門が読み手。専門用語は避ける
- 配色：ネイビー×ブルー基調＋アクセントに緊急の赤(#ef4444)、安心の緑(#16a34a)、スポットの琥珀(#f59e0b)

## 3. セクション構成とコピー（この通りに実装）

### ① ヒーロー
- エイブロー（小ラベル）：`退職・引き継ぎ業務の引き取りサービス｜Offboard`
- **H1：担当者が辞める。その引き継ぎ書、本当に足りていますか？**
- サブ：引き継ぎ書をつくっても「その人しか知らない作業」「たまにしか発生しない作業」はこぼれがち。**Offboardは、退職・休職する社員の業務をAIで引き継ぎ、そのまま巻き取ります。**
- 主CTAボタン：`無料で引き継ぎ診断（約60秒）` → offboard.hikitsugi.jp
- 副CTAボタン：`無料相談（30分）` → /contact
- 緊急バナー：`⚠ 退職日が迫っていますか？ 最短1週間で“ボールを落とさない体制”を作ります。`

### ② 痛みへの共感（背景ダーク or ライト）
- 見出し：`その引き継ぎ、こんな状態になっていませんか？`
- カード4枚：
  1. **後任が決まらないまま、退職日が近づいている**
  2. **引き継ぎ精度は9割止まり** — 辞める人のモチベは低く、資料は不十分
  3. **「その人しか知らない」属人業務がブラックボックス**
  4. **3ヶ月に1回の作業ほど漏れる**（季節セール・棚卸し・更新作業 等）
- 補足：派遣は採用に1〜2ヶ月、BPOは要件定義に1〜2ヶ月。**退職日には間に合わない。**

### ③ 解決＝Offboardとは（白背景）
- 見出し：`後任がいなくても、属人業務でも、業務は止めない。`
- リード：Offboardは、AIが主・人が監督する体制で、**退職者の業務を最短1週間で巻き取り**ます。引き継いで終わりではなく、**そのままAI化・運用代行**まで。
- **競合比較表**（4列：立ち上げ／丸投げ／AI化／価格）
  | | 立ち上げ | 丸投げ | AI化 | 価格 |
  |---|---|---|---|---|
  | 派遣 | ✕ 1-2ヶ月 | ○ | ✕ | 月40-60万 |
  | オンラインアシスタント | ○ 1週間 | ✕ 指示待ち | ✕ | 月数万〜 |
  | BPO会社 | ✕ 1-2ヶ月 | ◎ | △ | 月数十万〜 |
  | **Offboard** | **◎ 1週間** | **○ AI＋人** | **◎ そのまま** | 着手40万＋月40万〜逓減 |

### ④ 仕組み（3ステップ・ライト背景）
- 見出し：`引き継ぎから、その先のAI化まで。3ステップ`
1. **無料診断でタスクを棚卸し** — 抜け漏れがちなタスクを一覧化し、**引き継ぎ漏れのリスクを「金額」で可視化**（約60秒・無料）
2. **緊急巻き取り** — 1週間で“ボールを落とさない”最低ラインを確立、AI＋人SVが実務を代行
3. **そのままAI化・運用代行** — 業務を仕組み化し月額で継続運用（**AI化が進むほど料金は下がる**）

### ⑤ Offboardの強み「退職者に書かせない」（ダーク背景）
- 見出し：`引き継ぎの負荷を、辞める人から剥がす。`
- リード：従来の引き継ぎが失敗するのは「退職者に**書かせる**」から。Offboardでは退職者は **①喋る ②画面録画 ③ファイルを渡す** だけ。**文書化はAIが肩代わり**します。
- 補足：退職者が**在籍しているうちに実際の業務をドライラン並走**し、抜け漏れをその場で潰します。

### ⑥ 料金（白背景）
- 見出し：`料金`
- カード/表：
  - **引き継ぎ診断ツール：無料**
  - **引き継ぎ設計のみ：20万円**（巻き取りが難しい業務の棚卸し・SOP化まで）
  - **緊急巻き取り：着手40万円＋月40万円**（2-3ヶ月）
  - **AI化・運用代行：月30万円〜**（逓減・継続）
  - 注記：最初の数社は**アーリーアダプター価格（通常の50-70%）**
- 小さく免責：金額・診断結果はAIによる**概算**で、成果を保証するものではありません。

### ⑦ 運営・信頼（ライト背景）
- 見出し：`運営：ふえん株式会社`
- プロフィール：
  - 代表 安藤（ando@fuenn.co.jp）。**富士通から独立**。AIとノーコードで“エンジニアに頼らない”アプリ・システム開発を支援。
  - 著書『ノーコードシフト』『現場が動くDX』／ Podcast『聴くDX』『デジタルの仕組みラジオ』
  - 一般社団法人ノーコード推進協会 副代表理事
- AI-BPO 3原則（小さく明示）：**①AI主・人SV ②準委任・賠償は契約範囲（無料診断は免責） ③データは暗号化・学習不使用・契約終了後30日で削除**

### ⑧ 最終CTA（ダーク・グラデ）
- 見出し：`担当者の退職、引き継ぎは間に合います。`
- 主CTA：`無料で引き継ぎ診断` ／ 副CTA：`無料相談（30分）`

### ⑨ フッター
- 運営：fuenn.co.jp ／ プライバシーポリシー ／ 免責 ／ お問い合わせ
- 免責文：本サイトの無料診断はAIによる概算であり、内容の正確性・効果を保証しません。診断結果に基づく判断・損害について当社は責任を負いません。

## 5. 実装メモ・制約

- **既存 `.lp-*` クラス（.lp-wrap/.lp-section/.lp-hero/.lp-h2/.lp-lead 等）を最大限再利用**。新規スタイルは最小限の追記に留める
- 既存の旧コピー（CRM運用代行／ヒキツギAI／すまじむ 等の表記が残っていれば**すべてOffboardに置換・削除**）
- ボタンは既存のCTAボタン用クラスを流用。外部リンク（診断ツール）は `target="_blank" rel="noopener"`
- スマホ表示で崩れないこと（比較表は横スクロール or カード化）
- 変更は `front-page.php` 中心。フォーム送信先 `/contact` は既存 `page-contact.php` を使用（無ければ作成）
- 完了後 `./deploy.sh` でデプロイし、表示を確認

## 6. 参考：このLPの戦略背景（実装には不要・理解の助け）

Offboardは「オンラインで具体・緊急の“引き継ぎ”で集客 → 緊急巻き取り（スポット）→ そのままAI化・運用代行（月額）」という三段構えの**入口**。LPの役割は、不安を持つ訪問者を**無料診断ツール（offboard.hikitsugi.jp）へ送る**こと、緊急客を**無料相談へ送る**こと。会社名（ふえん）以外のブランドは「Offboard」に一本化している。
