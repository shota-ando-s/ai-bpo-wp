## 絶対に守ること

- **データファイルにない数値・事実を書かない。** 書きたい事実がデータにない場合は、WebFetch で一次情報（官公庁・自治体・公式サイト）を開いて確認できたときだけ書き、出典リンクを付ける。確認できなければ書かない。
- **架空の事例・実績・提携・顧客の声を書かない。** 試算は「当社試算」と明記し、前提を表で示す。
- **数値には、同じ文か直前の文に「時点」と「出典」を書く**（段落だけ抜き出されても正しいように）。表は直前の一文か表の下に出典と時点。
- 自治体名・制度名は正式名称。「市役所」「町役場」を正しく使い分ける（兵庫県に村はない）。
- 旧ブランド名「オフボード」「ヒキツギAI」は使わない。サービス名は「かんたんAI」、運営は「株式会社ふえん」（横浜市港北区）。**「東京の会社」「大阪の会社」「関西の会社」とは書かない**（兵庫県は大阪に近いので特に注意）。
- 今日は 2026年11月11日。補助金・事例・企業の確認日は「2026年11月11日時点」「2026年11月11日確認」（11月11日に確かめていない値は、データファイルの確認日のまま書く）。ファイル名の日付は 2026-11-11。
- 地名だけを差し替えたページにしない。市町ごとの固有データ（人口、産業、生成AIの導入状況、補助金、地元企業、主要産業での試算）で中身を変える。他の市町と同じ段落を使い回さない（「業務の引き継ぎにAIを使う」節も、その市町のデータで書き出しを変える）。**自分の担当ページ同士でも、書き終わったほかの担当のページとも段落を使い回さない。国の制度の表・相談先の表・試算の説明・FAQの回答も書き分ける。** とくに同じ県民局の近い市町（阪神南・阪神北の住宅都市、東播磨の加古郡の2町、神崎郡の3町、但馬の美方郡の2町、淡路島の3市など）、同じ業種の試算のページは組み立てから変える。
- **県・県域の事業を市町の施策と書かない**（末尾の【D3】の一覧。ひょうご産業活性化センター・兵庫県よろず支援拠点・兵庫県立工業技術センター・NIRO・県の補助金・県のDX支援事業は県・県域の事業・機関。姫路市の播磨圏域向けのセミナーは姫路市の事業）。**県庁・大企業の話と、中小企業が使える支援（研修・補助・相談）を分けて書く。**
- **大企業の工場（臨海部の鉄鋼・化学・機械・電機など）の話は【D1】の書き方だけ（統計の値と1〜2文）にとどめ、試算・業務の表・事例は中小企業の業種で書く**。「企業城下町」「◯◯の町」と書かない。

### 事例の書き方（H2 3・4・7 共通）

- **実在の企業・自治体・事業だけ**を書く。一次情報（企業・自治体の公式発表、官公庁・公的機関の資料、報道機関の記事）で確認し、出典リンクを付ける。AIベンダーの導入事例ページは、導入先の企業名と内容が明記されていれば使ってよい（「◯◯社（AIベンダー）の導入事例による」と書く）。
- 効果の数値は出典の文言どおりに書き、時期を添える。数値がなければ書かない。**実証・見込み・目標・理論値・試算・テスト段階・精度・受講者や職員の自己申告の数値は、そう書く**（【D2】の「事例ごとの数値の注意」）。
- 事例の企業を評価・推薦する言葉は使わない。かんたんAI・ふえんが関わった事例のように読める書き方をしない。
- 他地域の事例は、その市町の主要産業と同じか近い業種に限る。
- 同じ事例を複数の市町ページで詳しく書かない。【D2】の「事例の割り当て」で詳述と決めたページで詳しく書き、他のページでは1〜2文の要約と、そのページへのリンクにとどめる。**仕様が名指ししたページ以外では、他県で詳述した事例・企業に触れない。**
- **県・市の事業の成果報告・事例集・情報誌の事例**は掲載時点の紹介で、その後も使い続けているかは確かめていない。時点と出典を書く。開発・実証中のものを導入済みと書かない。研究・実証段階の精度を、導入の効果と書かない。
- **補助金の交付決定・採択一覧・計画名にだけ出る企業**は「採択された」「交付が決まった」までにとどめ、効果や導入済みと書かない。
- **AIとほかの施策（ロボット・自動機・RPA・クラウド・ペーパーレス）の効果が混ざる事例**は、AIだけの効果と書かない。出典が分けている効果だけをAIの効果として書く（HKテクノロジーの「7人分」「年間700万円」はロボットアームと自動機を合わせた値。【D2】）。
- 市町内に中小企業のAI事例がない場合は、そう明記したうえで、AI以外のDX事例を、AIではないと分かるように短く紹介してよい。
- URLに丸括弧を含むリンクは `%28` `%29` に置き換える（Markdownのリンクが途中で切れる）。
- 記事の出典リンクは**開けるものだけ**。近畿経済産業局（kansai.meti.go.jp）・姫路商工会議所（503）などはこのコンテナから開けないことがある。書く前に WebFetch か curl（ヘッダーを偽らない）で開けるか確かめ、開けなければ使わない（このコンテナからは Internet Archive にも接続できない）。**リンクの条件がある市町（【D3】の「リンクの条件」）は、その扱いに従う**。

### Web検索

WebSearch は**担当ごとに合計2回まで、できれば0回**。データにない事実を足したいときは、データにある公式URLか確実に分かっている公式URLを WebFetch か curl（ヘッダーを偽らない）で開き、確認できたときだけ書く。県外の事例を足すときは、使う前に `grep -rl "<社名>" articles/ data/` で他県の使用を確かめる。**仕様の「見つからない」「確認できなかった」は、執筆担当が一次資料を開いて違えば直してよい**。直したときは報告に書く。

- 県・市町のサイトは、このコンテナの curl で切断・証明書のエラー・503 になることがある（多可町は調査の間ずっと開けなかった）。WebFetch では開けることがある。WebFetch は要約を返すので、数値は PDF を curl で保存して pdftotext で確かめる
