# Offboard 営業LP 改修指示書 v2（2026-07-04 / ディレクション: Fable）

v1（`offboard-lp-brief.md`）を**置き換える**確定指示書。2026-06-22「4段ラダー」決定と2026-07-02「ビジネスモデル外部検証」決定を反映し、旧「丸投げ代行（緊急巻き取り着手40万＋月40万）」訴求をLPから完全に除去する。

- 対象: `themes/generatepress-child/front-page.php`（現行872行）の改修
- 方針: **BtoBのシンプルで分かりやすい営業LP**。既存の `.lp-*` デザインシステム・配色（ネイビー#0d1b4b×ブルー基調）・レスポンシブ挙動は維持。CSSの新規追記は最小限
- 読み手: 中小企業の経営者・管理部門。専門用語を避け、見出しはストレートに不安を突き、本文はやわらかく伴走

## 0. 最重要の変更点（why）

1. **売り物の再定義**: 「業務を丸ごと巻き取る代行」ではなく **「退職者の頭の中を抽出し、業務が止まらない状態を維持し続ける役務」**。ボット・アプリは手段。課金根拠は「抽出＋緊急対応＋運用責任」
2. **料金を4段ラダーに全面差し替え**: 旧「緊急巻き取り 着手40万＋月40万」「AI化・運用代行 月30万〜逓減」は**廃止済み**。残存すれば重大な誤り
3. **CTA変更**: 診断ツール `offboard.hikitsugi.jp` は**未稼働（DNS未登録）**のため、**全CTAを「無料相談（30分）」= `/contact/` に一本化**する。診断は「無料相談の中で実施」と表現。`$offboard_tool_url` 変数はコメント付きで残置（ツール公開時に診断CTAを復活させるため）。**外部リンクの診断ボタンは全て削除**

## 3. 実装制約

- `.lp-*` 既存クラスを最大限再利用。新規CSSは front-page.php 内の既存 style ブロックに最小限追記
- `無料相談` リンクはすべて `home_url( '/contact/' )`。**外部診断ツールへの `<a>` は全削除**（`$offboard_tool_url` は「ツール公開時に診断CTA復活用」とコメントを付けて変数定義のみ残す）
- 旧価格（着手40万／月40万／月30万〜逓減）・「丸投げ」「巻き取り」を主語にした旧訴求・自律実行デモUIが**1箇所も残らない**こと（grepで確認: `40万`, `30万〜`, `丸投げ`, `専用アカウント`）
- ※「巻き取り」の語自体は禁止ではないが、「業務を丸ごと巻き取る＝代行」と読める文脈では使わない。「引き取る」「写し取る」を優先
- レスポンシブ必須（比較表は横スクロール維持）。Font Awesome アイコンは現行の読み込みを流用
- PHP構文エラーゼロ（`php -l` で確認）。WordPressテンプレート構造（get_header/get_footer）維持
- デプロイはこの作業では**行わない**（コミットまで。デプロイはユーザ指示で）
