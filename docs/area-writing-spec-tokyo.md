## 絶対に守ること

- **数値には、同じ文か直前の文に「時点」と「出典」を書く**（段落だけ抜き出されても正しいように）。表は直前の一文か表の下に出典と時点。

### 事例の書き方（H2 3・4・7 共通）

- **実在の企業・自治体・事業だけ**を書く。一次情報（企業・自治体の公式発表、官公庁・公的機関の資料、報道機関の記事）で確認し、出典リンクを付ける。AIベンダーの導入事例ページは、導入先の企業名と内容が明記されていれば使ってよい（「◯◯社（AIベンダー）の発表による」と書く）。
- 効果の数値は出典の文言どおりに書き、時期を添える。数値がなければ書かない。**実証・見込み・目標・理論値・試算・テスト段階・精度・受講者の自己申告・「体感」の数値は、そう書く**（【D2】の「事例ごとの数値の注意」）。
- 事例の企業を評価・推薦する言葉は使わない。かんたんAI・ふえんが関わった事例のように読める書き方をしない。
- 他地域の事例は、その区の主要産業と同じか近い業種に限る。
- 同じ事例を複数の区のページで詳しく書かない。【D2】の「事例の割り当て」で詳述と決めたページで詳しく書き、他のページでは1〜2文の要約と、そのページへのリンクにとどめる。**仕様が名指ししたページ以外では、他県で詳述した事例・企業に触れない。**
- **都・区・公社の事業の成果報告・事例集の事例**は掲載時点の紹介で、その後も使い続けているかは確かめていない。時点と出典を書く。開発・実証中のものを導入済みと書かない。
- **補助金の採択・委託の一覧にだけ出る企業**は「採択された」までにとどめ、効果や導入済みと書かない。個人事業者の名前は書かない。
- **AIとほかの施策（設備・業務フローの整理・RPA）の効果が混ざる事例**は、AIだけの効果と書かない。
- 区内に中小企業のAI事例がない場合は、そう明記したうえで、AI以外のDX事例を、AIではないと分かるように短く紹介してよい。
- URLに丸括弧を含むリンクは `%28` `%29` に置き換える（Markdownのリンクが途中で切れる）。
- 記事の出典リンクは**開けるものだけ**。関東経済産業局（kanto.meti.go.jp）・Internet Archive・経産省・中小企業庁のサイトはこのクラウドの環境から開けない。東京商工会議所のサイトは curl で 403 のことがある（WebFetch で開ければ使ってよい）。書く前に WebFetch か curl（ヘッダーを偽らない）で開けるか確かめ、開けなければ使わない。**リンクの条件でリンクしないサイト（【D3】の「リンクの条件の記事での扱い」）には、開けてもリンクしない**。
