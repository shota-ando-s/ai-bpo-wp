## 絶対に守ること

- **データファイルにない数値・事実を書かない。** 書きたい事実がデータにない場合は、WebFetch で一次情報（官公庁・自治体・公式サイト）を開いて確認できたときだけ書き、出典リンクを付ける。確認できなければ書かない。
- **架空の事例・実績・提携・顧客の声を書かない。** 試算は「当社試算」と明記し、前提を表で示す。
- **数値には、同じ文か直前の文に「時点」と「出典」を書く**（段落だけ抜き出されても正しいように）。表は直前の一文か表の下に出典と時点。
- 自治体名・制度名は正式名称。「市役所」「町役場」「村役場」を正しく使い分ける（当別町は町役場、新篠津村は村役場）。
- 旧ブランド名「オフボード」は使わない。サービス名は「ヒキツギAI」、運営は「株式会社ふえん」（横浜市港北区）。「東京の会社」とは書かない。
- 今日は 2026年11月6日。補助金・事例・企業の確認日は、データの確認日（多くは2026年11月5日）をそのまま書くか、執筆で開き直したら「2026年11月6日確認」。ファイル名の日付は 2026-11-06。
- 地名だけを差し替えたページにしない。市町村ごとの固有データで中身を変える。**自分の担当ページ同士でも、書き終わったほかの担当のページとも段落を使い回さない。国の制度の表・相談先の表・試算の説明・FAQの回答も書き分ける。**
- **道・道域の事業を市町村の施策と書かない**（北海道中小企業総合支援センター〔HSC〕・北海道よろず支援拠点・ノーステック財団・道総研・北海道プロフェッショナル人材センター・道の補助金・道の Society5.0 の事業は道・道域の事業・機関。札幌市にあっても札幌市の施策ではない）。**さっぽろ産業振興財団（札幌市エレクトロニクスセンター）・札幌中小企業支援センターは札幌市の外郭の機関**で、札幌市の事業として書いてよいが、ほかの市町村の窓口と書かない。**道庁・大企業の話と、中小企業が使える支援（研修・補助・相談）を分けて書く。**
- **大企業の工場・空港・自衛隊・データセンター・球場（千歳市の Rapidus の工場、新千歳空港、自衛隊の基地、石狩市のデータセンター、北広島市のエスコンフィールドHOKKAIDO など）は、公式資料で確かめた事実と統計の値を1〜2文にとどめ、試算・業務の表・事例は中小企業の業種で書く。** 中小企業への波及・取引の増加など、資料にない影響を書かない。
- **ベンダーが「AI」と呼ぶシフト作成・配車・オンデマンド交通・電話応答のサービスは、中身を書き添える**。生成AIと混同しない。
- **観光地・国立公園・災害（北海道胆振東部地震〔2018年〕）・原子力発電所（泊村）・自衛隊・アイヌ文化の施設は、資料の事実と時点だけを書き、評価しない。** AIの事例として扱わない。観光の値は【D1】の書き方だけを使う。
- **国の出先機関は北海道経済産業局（札幌市）・北海道農政事務所（札幌市。「北海道農政局」はない）・北海道財務局（札幌市。函館・旭川・釧路・帯広の財務事務所と北見・小樽の出張所）・北海道労働局・北海道運輸局・国土交通省北海道開発局。** 「関東経済産業局」「東北経済産業局」「農政局」「九州財務局」「福岡財務支局」など他県の仕様の局名を書かない（**他県の仕様から写すと残る**）。**北海道経済産業局のサイト（hkd.meti.go.jp）はこのコンテナから 403** なので記事でリンクしない（国の補助金の締切は national.yml と /ai-bpo-subsidy-guide/ で書く）。北海道開発局は国の機関で、道の施策と混同しない。

- **他の都府県の値と並べない**（全国の値は並べてよい）。道の値と市町村の値を取り違えない（後継者不在率・休廃業・生成AIの利用率などを市町村の値と書かない）。**札幌市の値を北海道の値と書かない**（逆も）。
- **他の都府県のページへのリンクは張らない**（他県の市町村を「近隣」として挙げない）。茨城・栃木・群馬・沖縄の会社の事例は使わない（data/area/_batch5/shared.md の「事例の割り当て」）。

## 構成（H2 は次の順。見出しは検索クエリの形にする）

文字数の目安: **札幌市 9,000〜11,000字、ほかの市 6,500〜9,000字、町村 4,500〜7,000字**。無理に水増ししない。事例が見つからない節は短くてよい。

1. **リード（300字以内、H2なし）**: 一文目で「<市町村名>の会社がAIで何をできるか」を、その市町村の主要産業に即して言い切る。続けて箇条書き3点: 主要産業でAIに任せやすい業務／市町村内・道内のAIの事例（実証・導入）／使える補助金（市町村独自の制度の有無を一言）。最後に補助金診断 `/shindan/` と道のページ `/area/hokkaido/` へのリンク。
2. `## <市町村名>の会社はAIで何ができる？<主要産業>で効果が出やすい業務` — 経済センサスの業種構成、主要産業、有効求人倍率（**ハローワーク名と時点。管轄全体の値**。書き方は【D1】）、生産年齢人口の変化（令和7年国勢調査の15〜64歳の2020→2025年の増減）を短く示し、業種ごとにAIで減らしやすい業務の表（3〜5行、列: 業種／AIに任せやすい業務／使うAIの種類）。他県の値と並べない。
3. `## <市町村名>・北海道のAI導入事例` — **実在の企業・自治体の事例だけ**。市町村内の企業の事例 → 道内の同じ業種の事例、の順。各事例は「企業名（所在地・業種）／時期／何の業務にどんなAIを使ったか／効果（数値は出典の文言どおり）」と出典リンク。市町村内に企業の事例がなければ「2026年11月6日の調査では、<市町村名>の企業がAIを導入した公開事例は見つかりませんでした」と書き、道内の事例に進む。市役所の実証はここではなくH2 7で書く。
4. `## <主要産業>のAI活用事例：他の地域の会社は何に使っている？` — 道外の、その市町村の**主要産業と同じか近い業種**の事例（【D2】の割り当て）。最後に「<市町村名>の会社に当てはめると」として、どの業務から始めるとよいかを1段落で（当社の見方と明記）。割り当てがないページは「見つからなかった」と短く書く。
5. `## 試算：<市町村名>の<主要業種>（従業員<N>名）でAIを入れた場合` — **業種・業態・規模・対象業務・人数・業務量は【D1】の割り当て表のとおり**（`data/area/hokkaido/_calc.py` の PLAN。他県の PLAN と照合済みなので変えない）。前提表（対象業務／対象人数と業務量〔仮定〕／削減率25%〔未検証の仮定〕／時間単価〔仮定。wages.md の業種の時給×1.2〕）と結果表（**月の削減時間／月の時間換算額〔年間〕の2行だけ**）。前提表に「<市町村名>内の中規模の事業所の例（仮の会社）」と書く。**ヒキツギAIの月額・差し引き・初期費用の回収期間は書かない**。結果表の後に、(1) 削減率・人数・時間・時間単価は当社試算の仮定で当地の企業で測った値ではないこと、Noy & Zhang の[実験](https://pubmed.ncbi.nlm.nih.gov/37440646/)は参考資料でその業務の25%削減を実証したものではないこと、(2) **金額は業務余力の目安で、給与・残業代・外注費などの支出が同額減ることを意味しないこと、導入費・月額利用料・確認の時間は差し引いていないこと、回収期間は算出しないこと**、を書く（**文は写さず書き分ける**）。計算は python で確かめる。**結果表は見出しの行だけにせず、2行の中身を必ず入れる**。試算の節で事例の会社に触れない。**時給は全国の値で、北海道の賃金は全国より低い（wages.md の参考値）ことを1文で添えてよい**（数値を書くなら wages.md の出典と時点）。
