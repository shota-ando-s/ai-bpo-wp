# 市区町村ページ 執筆仕様（青森県で使った版、2026-10-17）

> 青森県版（2026-10-17）。docs/area-writing-spec-kochi.md をコピーして青森県の値に置き換えた。東北で最初の県。データはリポジトリの data/area/aomori/ にある。末尾の「青森県のデータの補足」を必ず読む。


hikitsugi.jp の地域ページ。県ページ `/area/aomori/` の子として、市町村ごとに1ページ作る。
読者は、その市町村の中小企業の経営者・総務担当。狙う検索は「◯◯市 AI導入」「◯◯市 AI」。

> **2026-10-17 方針変更**：「◯◯市 AI導入」の検索上位は、市役所のAIの実証（スマートシティ、チャットボット共同実証など）の報道と国の資料が占め、中小企業向けに「自社で何ができるか」を答えるページがない。そこで、**自分の会社でAIを入れたい人をメインの読者**にし、「AIで何ができるか」と「近い業種の実際の事例」を前に出す。補助金は関心が高いので残すが、前面には出さず**中段**に置く。市役所の節では、生成AIだけでなく、**その市町村で過去に行われたAIの実証・事業**（報道・国の資料・実施企業の発表）も書く。
Google の AI Overview・AI モード・ChatGPT 検索に、段落単位で引用されることを狙う。

## 絶対に守ること

- **データファイルにない数値・事実を書かない。** 書きたい事実がデータにない場合は、WebSearch/WebFetch で一次情報（官公庁・自治体・公式サイト）を開いて確認できたときだけ書き、出典リンクを付ける。確認できなければ書かない。
- **架空の事例・実績・提携・顧客の声を書かない。** 試算は「当社試算」と明記し、前提を表で示す。
- **数値には、同じ文か直前の文に「時点」と「出典」を書く**（段落だけ抜き出されても正しいように）。表は直前の一文か表の下に出典と時点。
- 自治体名・制度名は正式名称。「市役所」「町役場」を正しく使い分ける。
- 旧ブランド名「オフボード」は使わない。サービス名は「ヒキツギAI」、運営は「株式会社ふえん」（横浜市港北区）。「東京の会社」とは書かない。
- 今日は 2026年10月17日。補助金の時点は「2026年10月17日時点」。
- 地名だけを差し替えたページにしない。市町村ごとの固有データ（人口、産業、生成AIの導入状況、補助金、地元企業、主要産業での試算）で中身を変える。他の市町村と同じ段落を使い回さない（「業務の引き継ぎにAIを使う」節も、その市町村のデータで書き出しを変える）。

## 構成（H2 は次の順。見出しは検索クエリの形にする）

文字数の目安: 青森市・八戸市・弘前市 8,000〜11,000字、他の市 6,000〜10,000字、町村 4,000〜6,000字。無理に水増ししない。事例が見つからない節は短くてよい。 人口の少ない村（今別町・蓬田村・西目屋村・風間浦村・佐井村・新郷村など）は短くてよい。同じ文章を使い回さない。

1. **リード（300字以内、H2なし）**: 一文目で「<市町村名>の会社がAIで何をできるか」を、その市町村の主要産業に即して言い切る（例:「平内町のほたて養殖の経営体や水産加工場では、作業日報と出荷記録の集計、取引先への連絡文の作成からAIを入れると効果が出やすく、県内でも弘前市のりんご園でAIを使った運搬ロボットを試した例などがあります。」）。続けて箇条書き3点: 主要産業でAIに任せやすい業務／市内・県内のAIの事例（実証・導入）／使える補助金（市独自の制度の有無を一言）。最後に補助金診断 `/shindan/` と県ページ `/area/aomori/` へのリンク。
2. `## <市町村名>の会社はAIで何ができる？<主要産業>で効果が出やすい業務` — 経済センサスの業種構成、主要産業、有効求人倍率（ハローワーク名と時点）、生産年齢人口の2050年見込み（社人研、当社算出）を短く示し、業種ごとにAIで減らしやすい業務の表（3〜5行、列: 業種／AIに任せやすい業務／使うAIの種類〔生成AI・画像認識・予測など〕）。
3. `## <市町村名>・<県名>のAI導入事例` — **実在の企業・自治体の事例だけ**。市町村内の企業の事例 → 県内の同じ業種の事例、の順。各事例は「企業名（所在地・業種）／時期／何の業務にどんなAIを使ったか／効果（数値は出典の文言どおり）」と出典リンク。市町村内に企業の事例がなければ「2026年◯月◯日の調査では、<市町村名>の企業がAIを導入した公開事例は見つかりませんでした」と書き、県内の事例に進む。市役所の実証はここではなくH2 6で書く（重複させない）。
4. `## <主要産業>のAI活用事例：他の地域の会社は何に使っている？` — 県外の、その市町村の**主要産業と同じか近い業種**の事例を2〜4件。地方の中小・中堅企業を優先し、大企業は1件まで。書き方はH2 3と同じ。最後に「<市町村名>の会社に当てはめると」として、どの業務から始めるとよいかを1段落で（当社の見方と明記）。
5. `## 試算：<市町村名>の<主要業種>（従業員<N>名）でAIを入れた場合` — 業種は wages.md にある業種から選ぶ（漁業・農業は毎月勤労統計に時給がないので、水産加工・食料品なら「製造業」、農協・卸なら「卸売業・小売業」のように統計がある業種で試算し、その旨を前提表に書く）。主要業種はその市町村で従業者か出荷額が大きい業種を選ぶ（他の市町村と業種・規模・対象業務をできるだけ変える）。対象業務は H2 3・4 の事例に近いものにする。前提表（対象業務／対象人数と業務量〔仮定〕／削減率25%〔Noy & Zhang 2023 の40%を割り引いた値〕／人件費時給〔wages.md の業種の時給×1.2〕）と結果表（月の削減時間／月の削減額〔年間〕／ヒキツギAI（AIチャット）月5万円〜／差し引き／初期費用50万円の回収期間）。**計算は python で確かめる。回収期間は 50万円÷（月の削減額−5万円）を小数1桁まで計算して「約◯か月」と丸める（例 5.5→約5か月半）。差し引きがマイナスや小さすぎる設定にしない。** 出典行（時給の統計、Noy & Zhang の PubMed リンク https://pubmed.ncbi.nlm.nih.gov/37440646/ 、仮定である旨）。
6. `## <市町村名>でAI導入に使える補助金はある？（2026年10月時点）` — **中段に置く**。一文目で答える。市町村独自の制度の表（制度／実施主体／上限・補助率／AIへの使い道／締切・状況）。なければ「独自の制度はない」と根拠つきで書き、国と県の受付中の制度を表に（国: デジタル化・AI導入補助金〔6次締切 2026/10/30 17時〕、人材開発支援助成金、働き方改革推進支援助成金〔11/30〕、省力化投資補助金カタログ注文型〔随時〕、小規模事業者持続化補助金 第20回〔11/5〜12/15〕のうち該当するもの）。青森県の制度は subsidy_a.yml の県の行から（青森県には国の補助金への県の上乗せ制度はない。県の主な補助金は今年度の公募を終えたものが多いので、終了は終了と書く）。国の制度の詳細は national.yml と /ai-bpo-subsidy-guide/ にリンク。
7. `## <市町村名>の<市役所|町役場|村役場>はAIを使っている？これまでの実証` — 「<市町村名> AI」で来る人向け。(a) 総務省の生成AI導入団体詳細調査（2025年10月31日時点）の結果と全国の導入率（その他市区町村 45.6% など、gov_ai.md の値）、(b) **その市町村で過去に行われたAIの実証・事業**（スマートシティ、AIチャットボットの共同実証、AI-OCR、交通・防災・保育のAIなど。報道・国の資料・実施企業の発表で確認できたもの、時期と実施主体と結果）、(c) DX計画。出典リンク必須。過去の実証は一次情報で確認できたものだけ書き、結果が分からなければ「結果は公表資料では確認できなかった」と書く。
8. `## <市町村名>のシステム開発・Web開発会社` — 下の「地元のIT企業」の書き方に従う。
9. `## <市町村名>でAI導入を無料で相談できる窓口は？` — 商工会議所・商工会、青森県DX総合窓口、21あおもり産業総合支援センター、青森県よろず支援拠点（弘前・八戸サテライト、出張相談会、毎週月曜のAI相談会）、八戸市のデジタル化・DXサポートセンター（八戸圏域の町村も対象）など、*_areas.md と gov_ai.md にあるもの。表で。
10. `## 業務の引き継ぎにAIを使う` — その市町村の生産年齢人口の減少率や後継者不在（青森県の値と明記）から書き出す。ヒキツギAIの説明（担当者しか知らない業務の進め方や判断の基準をAIに蓄え、後任が質問すれば答えられる状態にする）と箇条書き3点、料金（AIチャット月5万円〜、AI自動化月20万円〜、初期導入費は別途お見積もり、税抜）、リンク `/knowledge-sharing-guide/` `/handover-guide/`。最後に「ふえんは横浜市港北区を拠点に、東京・首都圏のAI企業ネットワークから得た活用方法を、<市町村名>の会社の事情に合わせて導入します。」
11. `## よくある質問` — `### 質問？` を7問。一文目（80字以内）で直接答え、出典リンクを回答の中に1つ以上入れる。必須の質問: 「<市町村名>の<主要産業>ではAIを何に使えますか？」「<市町村名>や<県名>でAIを導入した会社の事例はありますか？」「<市町村名>にAI導入の補助金はありますか？」「<市町村名>の<市役所|町役場|村役場>はAIを使っていますか？」「<市町村名>でシステム開発やAI導入を相談できる会社はありますか？」「情報はいつ時点のものですか？」。残り1問は serp.md のサブ質問から、その市町村に合うもの。
12. `## まとめ` — 箇条書き4〜5点（市町村固有の数値・事例を含む。補助金は1点だけ）＋ 補助金診断・県ページへの導線。
13. `## まずは無料のAI活用診断から` — お手本と同じ文と `[無料でAI活用診断を申し込む](/contact/)`。

### 事例の書き方（H2 3・4・7 共通）

- **実在の企業・自治体・事業だけ**を書く。一次情報（企業・自治体の公式発表、官公庁・公的機関の資料、報道機関の記事）で確認し、出典リンクを付ける。AIベンダーの導入事例ページは、導入先の企業名と内容が明記されていれば使ってよい（「◯◯社（AIベンダー）の導入事例による」と書く）。
- 効果の数値は出典の文言どおりに書き、時期を添える。数値がなければ書かない。
- 事例の企業を評価・推薦する言葉は使わない。ヒキツギAI・ふえんが関わった事例のように読める書き方をしない。
- 他地域の事例は、その市町村の主要産業と同じか近い業種に限る（例: 弘前市はりんご＝果樹、平内町・むつ市はほたて＝貝類養殖、十和田市は養豚、南部町は介護）。
- 同じ事例を複数の市町村ページで詳しく書かない。事例の企業がある市町村のページで詳しく書き、近隣の市町村では3〜4行の要約と、そのページへのリンクにとどめる。
- 市町村内に中小企業のAI事例がない場合は、そう明記したうえで、市町村のDX支援拠点などに載っているAI以外のDX事例を、AIではないと分かるように短く紹介してよい。
- MLITなどURLに丸括弧を含むリンクは `%28` `%29` に置き換える（Markdownのリンクが途中で切れる）。

## 地元のIT企業の書き方（H2 8）

一文目: 「<市町村名>に本社があるシステム開発・Web開発の会社を、公式サイトに掲載された従業員数の多い順に<N>社紹介します（2026年10月17日確認）。」（従業員数がない会社を資本金で並べた場合はそう書く）

| 会社名 | 所在地 | 従業員数 | 主な事業 |
|---|---|---|---|
| [正式社名](公式URL) | <市町村名><町名> | <N>名（<時点>） | <事業内容の要約> |

- 従業員数が公開されていない会社は「非公開」と書き、資本金を主な事業の欄の末尾に（資本金◯万円）。
- AI関連の取り組みが公式サイトに明記されている会社は、主な事業の欄に「AI〜にも対応」と短く。
- 評価・ランキング・おすすめの言葉は使わない。
- 該当する会社がない町: 「<町名>に本社があるシステム開発・Web開発の会社は、2026年10月17日の調査では見つかりませんでした。」と書き、データに近隣の市町村の参考情報があれば「近隣の<市名>の会社」として表に（その旨を明記）。なければ県ページ `/area/aomori/` と青森市のページ `/area/aomori/aomori-city/`（三八地域は八戸市 `/area/aomori/hachinohe/`、中南・西北地域は弘前市 `/area/aomori/hirosaki/` も） へ案内。

表の後に必ず次の2段落（文言は固定）:

> AIの導入やシステム開発は、掲載している会社に直接ご相談いただくことも、ヒキツギAI（株式会社ふえん）にご相談いただくこともできます。ふえんにご相談いただいた場合は、地域の事情に詳しい会社と組んで進めることもできます。

> 掲載している会社は、公式サイトなどの公開情報をもとに選んでいます。掲載は各社とふえんとの提携や推薦を示すものではありません。掲載内容の修正や削除のご依頼は、[お問い合わせ](/contact/)から受け付けます。

- stats.md: 人口（社人研）、経済センサス（中分類つき。常用雇用者規模は「北海道〜福島県」の地域ファイル）、製造業（**経産省「2025年経済構造実態調査 製造業事業所調査 地域別統計表」＝出荷額は2024年実績、個人経営を除く全事業所**。町村は製造業計だけ。今別町・蓬田村・西目屋村・新郷村は製造業計も秘匿）、農業（2025年農林業センサス 県分）と**市町村別農業産出額（推計、2023年。品目名＝りんご・米・豚・メロン・やまのいも等が書ける）**、漁業（2023年漁業センサス 県分。魚種は分からない。漁業種類＝ほたてがい養殖・いか釣・定置網・まぐろはえ縄まで）、市町村ごとの主要産業の候補、県の地域区分（統計の6地域）

- gov_ai.md: 総務省の生成AI・AI導入調査（県と40市町村の表）、県と10市の節。gov_ai_b.md: 22町8村の節。【二次情報】/ verified: false /【検索結果のみ】の項目は使わない
- subsidy_a.yml / subsidy_a_areas.md（県と10市、県全体の相談窓口）、subsidy_b.yml / subsidy_b_areas.md（30町村。商工会・担当課の連絡先あり）。confidence: secondary は使わない
- companies.json / companies.md（地元のIT企業）
- cases.md（県内のAI事例。末尾に「追加調査（cases2）」の節）、cases_outside.md（県外の同業種の事例、本文用20件）
- serp.md（検索意図、FAQのサブ質問21個）、wages.md（時給。全国値を使う。県の参考値は使わない）
- 国の制度: data/subsidies/national.yml。国の制度の書き方・URLは高知県のページ（例: articles/2026-10-17-area-kochi-muroto.md の補助金の節）と同じでよい
- **品目**（りんご・ほたて・いか・さば・まぐろ・にんにく・ながいも等）: 農産物は stats.md の市町村別農業産出額（agri_out2023）にある品目と金額だけ書ける。水産物の魚種・水産加工品の品目は統計にないので、書くなら gov_ai*.md・cases.md の一次情報か、自治体・漁協・企業の公式ページを WebFetch で開いて確認した出典を付ける（大間のまぐろ・陸奥湾のほたて等も同様）。「食料品製造業の出荷額＝水産加工の出荷額」とは書かない

### 東北で最初の県なので、四国と違うところ

- 事業承継・社長年齢・休廃業は **TDB青森支店の青森県版**がある。人手不足と生成AIは **TDB仙台支店の東北版**だけで、青森県の値はない。「青森県の正社員不足◯%」「青森県の生成AI活用率◯%」とは書かない。書くなら「東北6県の調査（有効回答742社）で正社員が不足している企業は50.3%」「東北6県の調査（有効回答748社）で生成AIを『活用している』は30.1%」と、地域と母数を書く
- 県内企業のAIへの関心は、**県の実態把握調査**（2025年10〜12月、回答1,478事業者）で「取り組んでみたいDX施策」に「AIの活用」を挙げたのが37.8%。利用率ではないので「AIを使っている企業が37.8%」とは書かない
- **地域区分**: 県の統計の6地域（東青・中南・三八・西北・上北・下北）を使う。**地域県民局は2025年4月1日に廃止された**ので「◯◯地域県民局の管内」と現在形で書かない。「津軽」「南部」「下北」の別は県資料で市町村の対応を確認できていないので、市町村を割り当てる形では書かない（「津軽地方のりんご」のような一般的な言い方も、出典がなければ避ける）
- **原子力関連施設**（六ヶ所村・東通村・大間町）: 立地・施設名・事業者などの事実だけを、gov_ai_b.md の出典（県資料）どおりに書く。評価（安全性・是非・経済効果の良し悪し）は書かない。AIの事例として扱わない。統計は業種構成（非鉄金属製造業・技術サービス業・電気業・建設業）の値まで
- 三沢市の公務（航空自衛隊・在日米軍関係）は経済センサス（民営）に入っていない。三沢市のページで米軍・自衛隊に触れるなら「経済センサスは民営事業所の統計で、基地の雇用は含まない」と添え、人数は書かない（データにない）
