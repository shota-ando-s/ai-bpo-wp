# 企画書: 地域別AI導入メディア（市区町村・都道府県 × AI）

> 2026-10-14 起案（web-sales セッションでの壁打ちをもとに作成）。
> 実装は本リポジトリ（hikitsugi.jp / WordPress）で行う。
> **未確定事項と要検証事項は末尾にまとめている。実装前にそこから着手すること。**

## 1. 目的

- 「◯◯市 AI」「◯◯県 AIエージェント」「◯◯市 AI 補助金」などの地域×AIの検索、とくに Google の AI Overview（AIO）や生成AI検索で引用されることを狙う。
- 各地域のページから、ふえんのAI導入支援（AIコンサル、ヒキツギAI）への相談につなげる。
- 副次的な目的として、**地域のIT企業をパートナーとして開拓する**入口にする。

## 2. 掲載する内容（ユーザー要望）

1. 各地域のAI活用・AI施策の詳細
2. 各地域のAI関連会社の一覧
3. 国や自治体の補助金・助成金の一覧
4. ふえんのAIコンサルやヒキツギAIの導入に使える補助金の一覧
5. AI導入の一般的な費用相場
6. 東京のふえんと地域のAI関連会社が組む意味

## 3. ポジショニング：「なぜ東京×地域パートナーか」

ユーザーの言葉を要約したもの（この主張がメディア全体の軸になる）。

- **東京**：AIの研究でも実装方法でも事例が最も多く、一次情報を得られる。ふえんは東京のAI関連企業とつながりが深く、**ネットにまだ出ていない事例も得られる**。
- **地域**：その地域、その業種業態、その顧客を知っているのは地域のIT企業である。
- **組む意味**：両者がタッグを組むことで、最新のAI活用方法を各社の事情に合わせて導入できる。

**表記の注意**：ふえんの所在地は横浜市港北区。「東京の会社」とは書かず、「東京・首都圏のAI企業ネットワーク」「東京圏のAI一次情報」と書く。会社概要と矛盾させない。

## 4. ヒキツギAIの位置づけ

- メディアは「AI導入全般」を扱い、ヒキツギAIは**分かりやすい入口商品**として扱う。
- 地域ページでは、人手不足、高齢化、退職、産休・育休、事業承継などの地域データから「担当者しか知らない業務」の課題へつなげ、ヒキツギAIを紹介する。
- 狙うキーワード：「◯◯市 業務引き継ぎ AI」「◯◯県 退職 引き継ぎ」「属人化 AI ◯◯」。
- 価格（hikitsugi.jp 掲載値、税抜）：活用診断は無料、AIチャットは月5万円〜、AI自動化は月20万円〜、初期導入費は別途見積もり。

## 6. 地域ページのテンプレート

1. **冒頭の要約（3〜5行）**：その地域で使える補助金の件数と上限額、主な相談先。AIOに引用させたい答えを書く。
2. **地域の産業とAI活用の余地**：主要産業ごとのユースケース。
3. **自治体のAI・DX施策**：DX計画、生成AIの導入状況、実証事業。
4. **使える補助金の表**：国・県・市の制度名、上限、補助率、締切、公式URL、**最終確認日**。
5. **地域のAI関連会社一覧**：社名、得意分野、所在地、ふえんとの連携有無。
6. **費用の目安と補助金を使った場合の実質負担の試算**（`/cost/` へリンク）。
7. **東京×地域パートナーの説明**（短く書き、`/why-local/` へリンク）。
8. **FAQ**（7問以上。FAQPage 構造化データを付ける）。
9. **CTA**：無料のAI活用診断。

### `/subsidy/fuenn/` への示唆

1. **当面の主役は厚労省の助成金**：AI研修（人材開発支援助成金）と、労働時間削減を目的とするコンサル（働き方改革推進支援助成金）。ベンダー登録が要らず、すぐ提案できる。
2. **デジタル化・AI導入補助金は「使えます。お問い合わせください」と案内する**：今年度の残りは6次（10/30締切）と7次（12/1締切、公式では未確認）だけで、今年度の申請には間に合わない見込み。来年度（2027年度）の公募で使う前提で、ページでは次のように書く。
   > ふえんのAI業務効率化サービスは、デジタル化・AI導入補助金（旧IT導入補助金）を使って導入できます（2027年度の公募から対応予定）。対象になるかどうか、申請の進め方はお問い合わせください。
   - 「対応予定」の注記は、ふえんの事業者登録とツール登録が完了したら外す。
   - 2027年度に制度が続くことが公表されたら、公募回と締切を追記する。
   - 準備すること：ヒキツギAIを「業務プロセスを持つツール」として登録できるパッケージにまとめる（チャットだけでなく業務自動化を含むAI業務効率化全般として）。上限を明記した価格表と導入実績資料を作る。事業者登録用に、直近の財務諸表、履歴事項全部証明書、販売実績を揃える。
3. **ヒキツギAIの訴求**：両立支援等助成金の「業務の標準化」の要件と、事業承継（M&AのPMI）に絡める。いずれも「ツール費が直接補助される」とは書かない。
4. 既存記事 `ai-bpo-it-hojo` は、2026年度の制度内容と照合して直す。7次以降に給与要件が追加された件を追記する。

## 9. SEO・AIO上のリスクと方針

- **大量生成ページへのスパム判定（scaled content abuse）に注意する。** 地名だけを差し替えたページは作らない。
- **公開は段階的に行う**：パイロット地域（神奈川県、東京都、ほか2〜3県）→ 47都道府県 → 政令市・中核市（約60市）→ データが揃った市区町村のみ。
- 各ページに一次情報（補助金、企業、自治体施策、事例）が**最低限揃わない地域は公開しない**。
- 補助金には公式URLと「最終確認日」を必ず載せる。更新の運用（例：月1回）を決める。
- 構造化データ：FAQPage、BreadcrumbList。企業一覧には ItemList も検討する。
- 執筆ルールは既存のSEOコンテンツ計画（メモリの project_content_plan）に従う：中小企業の視点、数値とROI、公的データの引用、失敗例も正直に書く、FAQは7問以上。

## 10. 実装方針（このセッションで決めること）

データ（地域、補助金、会社）は**構造化して持ち、ページはそこから生成する**のが前提。案は次の2つ。

- **A. 自作プラグイン `ai-bpo-area`**：カスタム投稿タイプ（area / subsidy / company）とテンプレートを持ち、データは JSON/YAML を git で管理して WP-CLI か REST で取り込む。運用はしやすいが、実装量が多い。
- **B. 既存の `post.py` を拡張**：データの YAML から Markdown を生成し、固定ページ（親子階層）として投稿する。早く出せるが、一覧やフィルタは弱い。

→ **決定（2026-10-14）：パイロットは B で出す。** `post.py` は現状は投稿（posts）専用なので、固定ページ（`pages`）と親ページ（`parent`）の指定に対応させる。47都道府県へ広げる段階で、一覧やフィルタが必要になったら A への移行を判断する。

### AI関連会社を掲載するときの運用

- **掲載条件**：公式サイトで、AIの開発、導入支援、研修のいずれかを事業として明示していること。本社か拠点が対象地域にあること。
- **掲載する項目**：社名、所在地（市区町村まで）、公式サイトに書かれている得意分野（要約し、出典URLを付ける）、確認日。評価や順位付けはしない。
- **事後連絡**：掲載から2週間以内に問い合わせフォームかメールで、掲載したことを知らせる。修正や削除の依頼を受け付けることと、パートナー募集（`/why-local/`）の案内を添える。
- **削除依頼**には5営業日以内に応じる。依頼の記録を残す。
- ふえんと連携済みの企業には「連携パートナー」のバッジを付けて区別する。
