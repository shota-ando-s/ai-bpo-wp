# 新しい県の地域ページを作る手順

愛媛県（2026-10-17）・香川県（同日）・徳島県（同日）で使った手順。県ページ1つと、県内の全市町村のページを作る。

## 成果物

| 成果物 | 場所 |
|---|---|
| 調査データ | `data/area/<pref>/`（形式は `data/area/kagawa/` に合わせる） |
| 執筆仕様（県版） | `docs/area-writing-spec-<pref>.md`（`docs/area-writing-spec-kagawa.md` をコピーして県の値に置き換える） |
| 県ページ | `articles/<日付>-area-<pref>.md`（`type: page` / `slug: <pref>` / `parent: area`） |
| 市町村ページ | `articles/<日付>-area-<pref>-<slug>.md`（`parent: area/<pref>`） |
| 補助金診断のデータ | `data/subsidies/<pref>.yml`、`data/subsidies/areas.yml` に県と市町村を追加 → `python3 scripts/build_shindan_data.py` |
| 地域ガイド | `articles/2026-10-14-area.md` の「四国の地域ページ」などの段に県を追加 |
| 重複率の確認 | `scripts/area_uniq.py` の県の選択肢に `<pref>` を追加 |
| 残作業 | `docs/area-todo.md` に県の節を作る |

## 手順

### 1. データを集める（並行してよい）

`data/area/kagawa/` の各ファイルが、そのまま調査項目の一覧になる。

- `stats.md`：人口（社人研 令和5年推計 suikei_kekka.xlsx）、令和3年経済センサス（第6-1表・第2-2表・第14表(5)。中分類も）、県の経済構造実態調査（製造業、市町村別・中分類別）、農林業センサス・漁業センサス、労働局の有効求人倍率（ハローワーク別・職業別、管轄市町村の一覧）、TDBの四国版（後継者不在率・社長年齢・人手不足・生成AI）、TDBの全国版（休廃業・解散の都道府県表）、県内の生成AI利用の調査、観光客数
- `gov_ai.md`：総務省「自治体における生成AI導入状況（令和7年度）」と詳細調査のxlsx（001070424・001070425、AI全般は001070421・001070422）から県と市町村の行、各市町村のDX計画、庁内のAI、**過去のAI実証**、企業向けのDX支援、商工会議所・商工会
- `subsidy_*.yml` / `*_areas.md`：県と市町村の、AI・デジタル化・研修に使える補助金（2026年度、受付状況つき）。独自の制度がない市町村は、確認したページを書く
- `companies.json` / `companies.md`：市町村に本社があるシステム開発・Web開発の会社（公式サイトで従業員数を確認）
- `cases.md` / `cases_outside.md`：県内企業のAI事例、主要産業と同じ業種の県外の中小企業の事例（愛媛・香川のページで使った事例と重ねない）
- `serp.md`：「◯◯市 AI」「◯◯市 AI導入」などの検索結果の状況、FAQ候補

注意：
- 一次情報（官公庁・自治体・企業の公式サイト、公的機関の資料、報道機関）で確認したものだけ。二次情報は `verified: false` / `confidence: secondary` で分け、記事では使わない
- 自治体サイトは短時間に大量アクセスすると 403 を返す。間隔を空ける
- WebSearch には1セッションの上限（200回）がある。調査を分けるときも全体で200回を超えない前提で配分する
- 調査をサブエージェントに任せたら、**全員の結果を受け取ってファイルに書いてから**次に進む

### 2. 執筆仕様を県版にする

`docs/area-writing-spec-kagawa.md` をコピーし、県名・slug・データの場所・「香川県のデータの補足」を新しい県の値に書き換える。特に次の3つを決めてから書き始める。

- 市町村ごとの主要産業（タイトル・試算・事例選びに使う。統計で裏づける）
- 事例の割り当て（同じ事例を複数ページで詳しく書かない。どのページで詳述するか）
- 県の値の使い方（後継者不在率などを市町村の値と書かない）

### 3. 書く（並行してよい）

- 構成・文体・チェックは執筆仕様のとおり。お手本は `articles/2026-10-17-area-yokohama.md`、県ページは `articles/2026-10-17-area-kagawa.md`
- 書き終えたら各ファイルで `check_article.py --kw "<市町村名> AI導入"` と `extract_claims.py --check-links` を ERROR 0 に。`python3 scripts/area_uniq.py <pref>` で各ページの「固有」60%以上
- 県ページの市町村一覧の地域区分は、県の資料（保健所の管轄など）で確認できる区分を使い、出典を付ける

### 4. 投稿・デプロイ（このMacでだけできる）

`.env`（WordPressのアプリケーションパスワード）とSSHの鍵はローカルにしかない。クラウドのセッションでは、ブランチにpushするところまで。

1. コミット
2. 県ページを先に投稿してから市町村ページ（親ページが要る）: `python3 post.py articles/<file>.md`
3. 地域ガイドを更新: `python3 post.py articles/2026-10-14-area.md`
4. `./deploy.sh`（補助金診断のJSONを反映）

新規投稿では、最初の3つのH2見出しにだけ画像を生成する（`post.py` の `MAX_H2_IMAGES`）。

### 5. 残作業を記録する

確認できなかったことは `docs/area-todo.md` に、何を見て確認できなかったかと一緒に残す。
