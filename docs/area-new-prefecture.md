# 新しい県の地域ページを作る手順

愛媛県（2026-10-17）・香川県（同日）・徳島県（同日）・高知県（同日）・青森県（同日。東北で最初の県）・岩手県（2026-10-18）・秋田県（同日）・宮城県（2026-10-23）・山形県（2026-10-24）・福島県（同日）・新潟県（同日）・富山県（2026-10-25）・石川県（2026-10-27）・福井県（同日）・岐阜県（2026-10-29）で使った手順。県ページ1つと、県内の全市町村のページを作る。

## 成果物

| 成果物 | 場所 |
|---|---|
| 調査データ | `data/area/<pref>/`（形式は `data/area/kagawa/` に合わせる） |
| 執筆仕様（県版） | `docs/area-writing-spec-<pref>.md`（`docs/area-writing-spec-kagawa.md` をコピーして県の値に置き換える） |
| 県ページ | `articles/<日付>-area-<pref>.md`（`type: page` / `slug: <pref>` / `parent: area`） |
| 市町村ページ | `articles/<日付>-area-<pref>-<slug>.md`（`parent: area/<pref>`） |
| 補助金診断のデータ | `data/subsidies/<pref>.yml`、`data/subsidies/areas.yml` に県と市町村を追加 → `python3 scripts/build_shindan_data.py` |
| 地域ガイド | `articles/2026-10-14-area.md` の「四国の地域ページ」などの段に県を追加 |
| 重複率の確認 | `scripts/area_uniq.py` の県の選択肢に `<pref>` を追加 |
| 残作業 | `docs/area-todo.md` に県の節を作る |

## 手順

### 1. データを集める（並行してよい）

`data/area/kagawa/` の各ファイルが、そのまま調査項目の一覧になる。

- `stats.md`：人口（社人研 令和5年推計 suikei_kekka.xlsx）、令和3年経済センサス（第6-1表・第2-2表・第14表(5)。中分類も）、県の経済構造実態調査（製造業、市町村別・中分類別）、農林業センサス・漁業センサス、労働局の有効求人倍率（ハローワーク別・職業別、管轄市町村の一覧）、TDBの四国版（後継者不在率・社長年齢・人手不足・生成AI）、TDBの全国版（休廃業・解散の都道府県表）、県内の生成AI利用の調査、観光客数
- `gov_ai.md`：総務省「自治体における生成AI導入状況（令和7年度）」と詳細調査のxlsx（001070424・001070425、AI全般は001070421・001070422）から県と市町村の行、各市町村のDX計画、庁内のAI、**過去のAI実証**、企業向けのDX支援、商工会議所・商工会
- `subsidy_*.yml` / `*_areas.md`：県と市町村の、AI・デジタル化・研修に使える補助金（2026年度、受付状況つき）。独自の制度がない市町村は、確認したページを書く
- `companies.json` / `companies.md`：市町村に本社があるシステム開発・Web開発の会社（公式サイトで従業員数を確認）
- `cases.md` / `cases_outside.md`：県内企業のAI事例、主要産業と同じ業種の県外の中小企業の事例（愛媛・香川のページで使った事例と重ねない）
- `serp.md`：「◯◯市 AI」「◯◯市 AI導入」などの検索結果の状況、FAQ候補

注意：
- 一次情報（官公庁・自治体・企業の公式サイト、公的機関の資料、報道機関）で確認したものだけ。二次情報は `verified: false` / `confidence: secondary` で分け、記事では使わない
- 自治体サイトは短時間に大量アクセスすると 403 を返す。間隔を空ける
- WebSearch には1セッションの上限（200回）がある。調査を分けるときも全体で200回を超えない前提で配分する
- 調査をサブエージェントに任せたら、**全員の結果を受け取ってファイルに書いてから**次に進む

### 2. 執筆仕様を県版にする

`docs/area-writing-spec-kagawa.md` をコピーし、県名・slug・データの場所・「香川県のデータの補足」を新しい県の値に書き換える。特に次の3つを決めてから書き始める。

- 市町村ごとの主要産業（タイトル・試算・事例選びに使う。統計で裏づける）
- 事例の割り当て（同じ事例を複数ページで詳しく書かない。どのページで詳述するか）
- 県の値の使い方（後継者不在率などを市町村の値と書かない）

### 3. 書く（並行してよい）

- 構成・文体・チェックは執筆仕様のとおり。お手本は `articles/2026-10-17-area-yokohama.md`、県ページは `articles/2026-10-17-area-kagawa.md`
- 書き終えたら各ファイルで `check_article.py --kw "<市町村名> AI導入"` と `extract_claims.py --check-links` を ERROR 0 に。`python3 scripts/area_uniq.py <pref>` で各ページの「固有」60%以上
- 県ページの市町村一覧の地域区分は、県の資料（保健所の管轄など）で確認できる区分を使い、出典を付ける

### 4. 投稿・デプロイ（このMacでだけできる）

`.env`（WordPressのアプリケーションパスワード）とSSHの鍵はローカルにしかない。クラウドのセッションでは、ブランチにpushするところまで。

1. コミット
2. 県ページを先に投稿してから市町村ページ（親ページが要る）: `python3 post.py articles/<file>.md`
3. 地域ガイドを更新: `python3 post.py articles/2026-10-14-area.md`
4. `./deploy.sh`（補助金診断のJSONを反映）

新規投稿では、最初の3つのH2見出しにだけ画像を生成する（`post.py` の `MAX_H2_IMAGES`）。

### 5. 残作業を記録する

確認できなかったことは `docs/area-todo.md` に、何を見て確認できなかったかと一緒に残す。

## 四国以外の県で調べ方が変わる点（青森県で分かったこと）

- **TDBの地域版**: 帝国データバンクの地域版は支店ごとに出る。四国は高松支店の「四国地区」版だったが、東北は仙台支店の「東北地方」版（URL例 `https://www.tdb.co.jp/report/economic/20260907-laborshortage202607-tohoku/`）と、県の支店の県版（例 `20251201-successor25y-aomori`）がある。**青森県は後継者不在率・社長年齢・休廃業が県版で出ているが、人手不足と生成AIは東北版だけで県別の内訳がない**。記事では「東北6県の調査（有効回答◯社）」と地域と母数を書き、県の値として書かない。県版の有無は、TDBのレポート一覧（地域で絞る）と、URLの形（`YYYYMMDD-<テーマ>-<県名ローマ字>`）を日付を変えて試して確かめる
- **休廃業・解散**は全国版（毎年1月）の都道府県別表と、県版（あれば）の両方で件数が一致するか確かめる
- **労働局**: 職業別の有効求人倍率は労働局によって出し方が違う。青森労働局は大分類のバランスシート（グラフのPDF）だけで、中分類（一般事務員・介護など）は新規求人倍率しかない。ハローワークの管轄は「ハローワークの管轄地域と所在地一覧」で確かめ、市が2つの安定所に分かれる場合（青森市の浪岡地区、平川市）を書き分ける
- **県の地域区分**: 県の出先機関（地域県民局など）は組織改正でなくなっていることがある（青森県の地域県民局は2025年4月1日に廃止）。県の統計の地域区分（推計人口の地域別の表など）を使い、所属市町村は郡・市の人口の足し上げで確かめる。「津軽・南部」のような歴史的な区分は、県資料で市町村の対応を確かめられなければ使わない
- **品目の統計**: 東北農政局の市町村別農業産出額（推計）で、農産物の品目（りんご・米・豚・やまのいも等）と金額が市町村別に取れる。水産物の魚種と食料品製造業の品目は統計にない
- **県内企業のAI利用率**: 四国のような県別の生成AI調査がない県がある。県の「DX・デジタル化の実態調査」（青森県は令和7年度、回答1,478事業者）に「AIの活用」を聞く設問があれば使うが、利用率ではなく関心（取り組んでみたい施策）なので書き分ける
- **県の補助金**: 高知県のような「国の補助金への県の上乗せ」がない県もある。県の補助金一覧（青森県は地域企業支援課の月ごとのチラシPDF）とDX推進課・産業支援センターのページで、今年度の受付状況を確かめる。終了した制度は終了と書き、来年度の見込みは書かない
- **商工会の連絡先**: 県商工会連合会のサイトが開けないときは、全国商工会連合会の公式名簿で名称・住所・電話を確かめられる
- **原子力関連施設がある県**: 立地・施設名・事業者などの事実だけを県資料で書き、評価は書かない。AIの事例として扱わない
- **同名・紛らわしい自治体**: 他県の自治体と同じ名前（青森県横浜町と神奈川県横浜市など）は、slug を変え（`yokohama-town`）、本文で県名を明示し、統計は自治体コードで照合する

- **県のオープンデータカタログ**: 統計の表が県のオープンデータカタログ（青森県は opendata.pref.aomori.lg.jp）にしかないことがある。カタログに接続できないとリンク確認が ERROR になるので、記事の出典リンクは県サイトの報道発表（「◯◯の結果を掲載しました」）や統計一覧のページを予備として使い、データファイルには元のURLも残す

## 岩手県で分かったこと（2026-10-18）

- **ファイル名の日付**: 岩手県は 2026-10-18。`scripts/area_uniq.py` は日付を問わず `2026-10-??-area-<pref>*.md` を拾うようにした
- **TDBの県版がない年がある**: 岩手県は2025年の後継者不在率・社長年齢の県版（盛岡支店）が見つからなかった。後継者不在率は仙台支店の東北版の都道府県表、社長年齢は全国版の都道府県表から県の値を取る。休廃業の県版は `/report/industry/` の下にあった（`/report/economic/` だけでなく両方試す）
- **職業別の有効求人倍率**: 岩手労働局の「常用求人・求職バランスシート」は中分類（一般事務・介護・自動車運転など）の有効求人倍率まで出ている（青森労働局は大分類だけ）
- **県の出先機関**: 岩手県の広域振興局（4局）は現存。県南広域振興局の管轄は局のページになく、県の広報誌で確認した
- **県の補助金**: 岩手県は「国の補助金への県の上乗せ」がない代わりに、市町村（花巻市・山田町、北上市は予算到達で終了）に国のデジタル化・AI導入補助金への上乗せがある。市町村の上乗せ制度は data/subsidies の `addon` で表す
- **県と同名の町**: 岩手町は slug を `iwate-town` にし、自治体コード（03303）で統計を照合した。依頼メモのコード（03302＝葛巻町）が間違っていたので、コードは社人研の表で確かめる
- **利用上限で止まったとき**: 執筆担当が止まっても下書きは残る。WIPコミットしてから、担当に SendMessage で再開を頼むと続きから仕上げてくれる

## 秋田県で分かったこと（2026-10-18）

- **TDBの県版がそろう県がある**: 秋田県は2025年の後継者不在率・社長年齢・休廃業に加え、生成AI（`20260622-genai-akita`）の県版も秋田支店から出ていた。人手不足だけは2026年の県版がなく、最新は2025年4月。県ごとに、テーマ×日付でURLを試してから東北版にするか決める
- **県内企業のAI利用率の調査が複数ある**: 県の実態調査（2024年7月、生成AI 3.5%）、TDB（2026年3月、32.2%）、民間団体（報道のみ、43.1%）。時期・定義・母数が違うので、仕様に「比べない」「報道のみは書かない」と書いておく
- **県の補助金に対象外の業種がある**: 秋田県の中小企業デジタル化導入支援事業費補助金は製造業・農業・漁業・医療・介護などが対象外。製造業の多い市町村で「使える」と書かないよう、仕様の補助金の節に業種の制限を書く
- **県域の支援機関の名前**: 秋田県は「あきた産業振興機構」ではなく「あきた企業活性化センター」。調査の依頼文で機関名を決めつけない
- **商工会がない村がある**: 大潟村は全国商工会連合会の名簿になく、任意団体の大潟村商工振興会がある。小坂町は町内に商工会がなく、町はかづの商工会を案内している
- **自治体の補助金の活用事例ページ**: 能代市の「ICT活用事例」のように、市の補助金を使った企業の事例を市が公開していることがある。県内企業のAI事例が少ない県では、補助金のページの関連リンクも探す
- **県と同名の市の slug**: 秋田市は `akita-city`（青森市・高知市と同じ）。美郷町のように他県にも同名の町がある町は、本文で郡名から一度書く
- **同じ担当の中で段落が似る**: 1人に町村を4〜5つ任せると、担当の中で段落が似て固有率が50%前後に落ちた（五城目町・八郎潟町・上小阿仁村・藤里町）。担当に「自分のページ同士でも段落を使い回さない」と書くか、似た町村を別の担当に分ける
- **利用上限**: 執筆担当を9人同時に起動したところ、全員が数分で利用上限に当たって止まった（ファイルは0本）。上限が戻ってから SendMessage で再開すると、続きから仕上げた

## 宮城県で分かったこと（2026-10-23）

- **政令指定都市**: 仙台市は1ページだけにし、5区のページは作らなかった（ユーザー決定）。区別の事業所数・従業者数・製造品出荷額は国の統計で取れるので、市のページの中で使う。観光客数は区別がなく旧市町別だけ
- **TDBの県版がまったくない県がある**: 宮城県はTDB仙台支店（東北6県を管轄）の所在県だが、後継者不在率・社長年齢・休廃業・人手不足・生成AIの県版がどれもなかった（URLを2,380通り試した）。県の値は東北版・全国版の都道府県表から取る
- **県の補助金の受付状況の表が古いことがある**: 宮城県のデジタル化補助金のページは、冒頭の表が「受付中」のまま、本文と応募要領では締切が過ぎていた。表ではなく要領の日付で判断する
- **段階式の上乗せ補助金**: 仙台生産性ブースト補助金（自己負担25万円までは全額、超えた分は1/2）のために、data/subsidies の addon に `remaining_tiered` を足した
- **公式サイトにつながらない町**: 亘理町・涌谷町は調査・執筆の間ずっと接続できなかった。Internet Archive の保存版で確かめ、町独自の制度は「ない」と断定せず「確認しきれていない」と書いた
- **試算の数字が重なる**: 35ページを並行で書くと、試算の結果（時間・金額）がほかのページとまったく同じになることがあった（名取市と女川町、大和町と角田市、美里町と大郷町）。担当への依頼で「書き終わったページの試算の表を見て前提を変える」と書き、最後に全ページの試算を並べて確かめる
- **執筆担当は同時に4人まで**: 1人終わるごとに次を起動したところ、利用上限で止まらなかった。コミットするときは、書き終えた担当のファイルだけを `git add` する（ワイルドカードで足すと、書きかけのページも入る）
- **地元のIT企業は仙台市に集中する**: 公式サイトで本社と従業員数を確かめられる会社は、仙台市以外では5市町だけだった。県のIT企業データベース（OPEN INNOVATIONみやぎ）とMISAの名簿が手がかりになる

## 山形県で分かったこと（2026-10-24）

- **試算の形を変えた**: 執筆の途中で、試算を「月の削減時間・月の時間換算額」だけにし、ヒキツギAIの月額・差し引き・初期費用の回収期間を書かない形に変えた（ユーザー決定）。金額は業務余力の目安で、支出が同額減ることを意味しない・導入費や利用料は差し引いていない・回収期間は算出しない、と書く。お手本は `articles/2026-10-24-area-yamagata-higashine.md` の試算の節。次の県の仕様はこの形でコピーする
- **お手本のページに似る**: 「お手本は東根市」と書いたら、後から書いた村山市・南陽市が東根市の文に似て、両方の固有率が55〜56%に落ちた。お手本は「形だけを見る。文は写さない」と依頼に書く
- **TDBの県版がそろう県**: 山形県は後継者不在率・社長年齢・休廃業・人手不足・生成AIの5テーマとも山形支店の県版があった（3,148通りのURLを試して8本）
- **県内の中小企業のAI事例が少ない**: 数値つきは数件だけ。県外事例・自治体の取り組みで補い、県の補助金の採択一覧（まるっとサポート・パワーアップ補助金）に出るAIの事業名は「採択された」までに留めた
- **他県で詳述した地元企業**: 後藤組（米沢市、宮城県東松島市で詳述）・IBUKI（河北町、高知県香南市で詳述）は、地元のページで1〜2文にした。仕様で触れてよいページを名指ししても、担当が別のページでも触れることがあるので、依頼文に「仕様が名指ししたページ以外では触れない」と書く
- **利用上限**: 執筆4人の同時起動でも、4人とも利用上限で止まった（W5〜W8）。上限が戻ってから SendMessage で再開すると、続きから仕上げた
