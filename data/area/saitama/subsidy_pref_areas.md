# 埼玉県（県・県域の機関）の AI・IT 向け補助金と無料・低額の支援（2026-11-12 確認）

データ本体は `subsidy_pref.yml`（3件。すべて県・公社の公式のページ・特設サイト・交付要綱で確認。curl で取得）。「受付中」でも予算に達すると締め切られる。**市町村の補助金は govsub_1〜4（subsidy_1〜4.yml・subsidy_1〜4_areas.md）**。`saitama-dx-donyu` はパイロットの `data/subsidies/saitama.yml` と同じ id（同じ制度を確かめ直した。saitama.yml に反映するときは条件・期間・checked を差し替える）。

**2026-11-12 時点で、県・埼玉県産業振興公社に企業が今申請できる IT・AI 導入向けの補助金はない。**
- 受付中（団体向け）: **公社の県内企業DX推進人材育成講座補助金**（経済団体・業界団体などが開く講座の講師謝金、1団体20万円上限、**2027-01-12 17時必着まで**・予算に達したら終了）。企業が直接申請するものではない
- 随時（県域・補助金ではない）: **ＤＸコンシェルジュ**（埼玉県DX推進支援ネットワーク〔事務局 公社〕のデジタル活用無料相談・IT企業とのマッチング、**無料**）、**SAITEC の AI・IoT化相談**（**無料**。支援でかかる部品は企業負担、職員の出張費は無料）、**埼玉県よろず支援拠点**（**無料**、大宮＋県内27か所）
- 11月12日以降のセミナー: 公社「ゼロから始めるAI基礎講座〔２〕」（**2026-11-27・12-04**、有料 24,200円〔会員〕・35,200円、**受付終了 11-26**）、ネットワーク「第4回DX推進セミナー」（**2026-12-04**、オンライン、**無料**、締切 12-02 12時）、公社「第2回ＤＸ先進事例視察研修」（**2027-02-03**、オンライン、**無料**、IT ベンダー・コンサルは原則対象外）。日時は gov_ai.md の表

**今年度の募集を終えた補助**: 県の**中小企業DX導入支援補助金**（DXツール〔ソフトウェア・クラウド。リース・サブスク最大1年分〕、**3/4・上限300万円・下限7万5千円**〔補助対象事業費10万円以上400万円以下〕、審査制。**第1期 7/1〜7/31・第2期 8/3〜8/31・第3期 9/1〜9/30・追加募集 10/1〜10/30〔各16時〕**。追加募集のあとの募集の告知はない）、県の**中小企業省力化支援事業補助金**（省力化機器の新規導入・設備更新、**2/3〔賃上げで4/5〕・上限1,000万円〔1,200万円〕**、**5/25〜7/17**、9/18 に254件交付決定。**DXツールは対象外**）。ほかにポータルの資金補助の一覧に「【募集終了】埼玉県副業・兼業人材活用促進事業補助金」「【募集終了】埼玉県即戦力人材確保支援事業補助金」（県、人材紹介手数料。IT 導入向けではないので yml に入れていない）、「【募集終了】中小企業組合基盤高度化支援事業 重点テーマ型（AI・IoT活用、デジタル化支援部分）」（埼玉県中小企業団体中央会、**中小企業組合**向け、ハード上限700万円・ソフト上限200万円・2/3以内。**年度・募集期間の記載がない**ので yml に入れていない。中央会 組合支援部 048-641-1315）

**対象業種・規模の制限**:
- DX導入支援補助金: 交付要綱 別表1の**中小企業者等**（製造業・建設業・運輸業 資本金3億円以下又は常勤300人以下、卸売業 1億円・100人、サービス業 5,000万円・100人、小売業 5,000万円・50人、ソフトウェア業・情報処理サービス業 3億円・300人、旅館業 5,000万円・200人、ゴム製品製造業 3億円・900人、その他 3億円・300人。組合等、一定の NPO 法人・社会福祉法人も可。**みなし大企業は除く**）。**業種の除外はない**。県内に**登記簿上の本店又は主たる事業所**、県内の自社の事業所で実施、**決算期を迎えていない創業者は対象外**
- 省力化支援事業補助金: 県内に本店又は主たる事業所の中小企業者等（みなし大企業は除く）。**1次産業（農業・林業・漁業）の省力化は対象外**、人手不足か賃上げのいずれかが要件
- DX推進人材育成講座補助金: **団体**（経済団体・業界団体・工業団地協同組合・金融機関・支援団体等）。県内企業の受講者が原則5名以上

**国の補助金への上乗せ（addon）は県・県域の機関にない。** DX導入支援補助金は「国・県・市町村等の他補助金と重複する事業」を対象外、省力化支援事業補助金も「国や県及び公的制度からの二重受給」を対象外とするので、国のデジタル化・AI導入補助金・省力化投資補助金と**同じ事業での併用はできない**（stacking の exclusive_with は、national.yml の id と事業が同じかを判定できないので書いていない）。**市の上乗せは川口市 DX推進補助金**（パイロット・govsub_1）。

**AIを名指しした制度**: DX導入支援補助金の導入例の表の「AI（画像認識）」（荷物・作物の自動判別、微細な不良の自動検出）と、対象外の「AI搭載ロボットなどハード主体の導入（DXツール運用に不可欠な場合は対象となり得る）」だけ。**生成AIの名指しはない**（AIの業務効率化ツールが「DXツール」に当たるかは事務局に確認）。補助金ではない SAITEC の AI・IoT導入支援事業（生成AIでのプログラム修正の体験環境）、公社の AI基礎講座・第4回DX推進セミナー（登壇企業が AI に触れる）、視察研修（AI自動見積システム）が AI に触れる。

**国の制度（national.yml）の確認**: `digital-ai-donyu` の 7次締切 2026-12-01 17:00 は依頼メモ（事務局で確認済み）と兵庫の gov の確認（2026-11-11、https://it-shien.smrj.go.jp/schedule/ ）による。今回は再取得していない。ネットワークのポータルの資金補助の一覧にも「デジタル化・AI導入補助金」「中小企業省力化投資補助金」「ものづくり補助金」（いずれも関東経済産業局の掲載）。

**経済産業局**: 関東経済産業局（経済産業省組織令 第102条。gov_ai.md）。局の施策ページは 403 で開けていない。
