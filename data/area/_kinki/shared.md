# 奈良・和歌山・滋賀の同時作成の共有メモ（2026-11-07）

奈良・和歌山・滋賀の地域ページを、別々のセッションで同時に作るための共有メモ。3県とも近畿経済産業局の管内（福井県と同じ。`data/area/fukui/` に近畿経済産業局の資料と、局のサイトが 403 だったときの確かめ方の記録がある）。書き足したらすぐ push する（`git pull --rebase origin main` のあと。衝突したら両方の行を残す）。

## 試算の時間の割り当て

月の削減時間（0.25時間刻み）×4 を3で割った余りで、県ごとに使う時間を分ける。既存の全県の記事・`data/area/*/_calc.py` の PLAN（北海道など作成中の県は push されていれば）とは `_calc.py` で照合する。金額が重なったら、先に PLAN を push した県を優先する。
