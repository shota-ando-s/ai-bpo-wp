# 福島県 会津・南会津の15町村と相双の10町村の補助金（AI・IT・DX・研修・販路・創業・事業再開向け）2026年度

確認日: 2026-10-24。町村の公式サイトの産業・商工・事業者向けページ、募集ページ・公募要領・要綱PDF、町村の例規集（南会津町・只見町・双葉町）で確認した。YAML は `subsidy_c.yml`（15制度）。

- 25町村とも、生成AI・AI導入・AI研修を名指しで補助する町村独自の制度はない。
- **パソコン・ソフトウェアを対象経費に明記している町村の制度は3つ。**
  - **柳津町**「小規模事業者後継者支援事業補助金」: 商工会員の小規模事業所の満50歳までの後継者に、就業に必要な簿記等のPCソフト・ハード機器、機材機器、後継者育成研修会の受講料等を**全額（上限30万円）**補助。出典は町の「令和8年度 助成金及び補助金交付金一覧表」だけで、個別ページ・要綱は見つからなかった。
  - **大熊町**「創業・本社機能移転促進補助金」: 備品等の調達費に**業務用パソコン**（リース・レンタル含む）。10/10・創業200万円。ただし福島イノベーション・コースト構想の重点分野か F-REI の研究開発分野の事業に限る。計画書の申請期限2027-01-29。
  - **南会津町**「経営拡大支援事業補助金」: 新商品開発事業の経費に「システム構築費等」（1/2・20万円）。専門家活用事業（経営改善・業態変更の専門家の謝金・旅費 2/3・30万円）もある。申請期間の記載なし。
- **ホームページ作成に使える町村独自の制度**: 檜枝岐村「民間事業者広告支援事業補助金」（ホームページの作成・リニューアル。5万円を超える部分の3/4・上限30万円。申請期間は回覧で周知）、会津坂下町「新事業創出支援補助金」（インターネットを使った販路開拓など 10/10・10万円。申請書の記載例が「商品PR用WEBページ作成委託費」）、会津美里町「小規模事業者持続的経営発達支援事業補助金」（国の持続化補助金の**不採択者**向け。ウェブサイト関連費を含む 1/2・40万円）。
- **研修費に使える町村独自の制度**: 柳津町（後継者育成研修会、上記）、会津美里町（中小企業大学校・福島県産業振興センター・テクノアカデミー・ポリテクセンター等の研修 1/2・年5万円。ページは2023-05-09更新）、会津坂下町（特定創業支援事業の研修 1/2・1万円）、大熊町「就労サポート補助金」（eラーニング・外部研修の受講料、研修開催の専門家謝金 1/2・上限200万円。**国の自立・帰還支援雇用創出企業立地補助金の交付決定を受けた企業に限る**）、飯舘村「はじめるサポート補助金」（資格取得の受講料を含む 75％・30万円）。
- **国の補助金への上乗せ（addon）は、25町村とも確認できなかった。** 会津美里町の制度は国の持続化補助金に「不採択」となった事業を補助する仕組みで上乗せではない。国のデジタル化・AI導入補助金・省力化投資補助金、県の生産性向上推進事業補助金・業務改善応援補助金に町村が上乗せする制度も見つからなかった。
- **南会津町「産業力強化支援事業補助金」**（gov_c 担当の照合依頼）: 要綱（令和8年4月1日告示第39号）第4条の対象経費は建物附属設備・機械及び装置・工具器具備品の取得だけ。**ソフトウェア・クラウド利用料・研修・委託費には使えない**。製造業・情報通信業・産業用ドローン研究開発の中小企業、商工会推薦、従業員2人以上。1/2・100万円。受付は2026-07-31で終了。
- **相双の町村の事業再開・創業向けの町独自の制度**:
  - **富岡町**「事業再開支援事業補助金」（3/4・500万円／地域要件で650万円、受付2026-06-05〜2027-01-29）と「創業・事業展開支援事業補助金」（同率、2026-09-30で終了）は、移設・撤去・賃借・施設整備・修繕・設備備品（再開補助）、施設整備・設備・開業周知の広報費（創業補助）に限られ、**ソフトウェア・研修・委託の区分はなく、インターネット利用料は対象外**。AI・ITツールの導入には使えない。
  - **大熊町**は上記の創業・本社機能移転促進補助金（パソコン可）と就労サポート補助金（研修可、立地補助金の交付企業に限る）。小売・飲食等向けの生活利便性向上施設支援補助金（人件費・水道光熱費・通信費・広告宣伝費、ページは2025-04-01）もある。
  - **浪江町**の町独自の事業者向け補助は、光熱水費（電気・上下水道のみ、2026年度で終了）、飲食店の食材調達、夜間交通、PRイベント出展、次世代自動車、再エネ設備で、**IT・デジタル化・研修に使えるものはない**（gov_d 担当の照合依頼。光熱水費等補助金の要綱第4条の対象は電気料・上水道使用料・下水道使用料の3つだけ）。
  - **飯舘村**「がんばる商工業者支援補助金」（ひろげるサポート 75％・60万円、プラス 100万円ほか）。対象経費は「お問い合わせください」で、ITツールが入るかは村に確認が必要。
  - 広野町・楢葉町・川内村・双葉町・葛尾村・新地町は、町村独自の事業再開・創業・IT向けの補助制度を公式サイトで確認できなかった（川内村はサイトに事業者向けの分類がなく「確認しきれていない」）。
- **福島県12市町村起業支援金**（県の制度。12市町村＝田村市・南相馬市・川俣町・広野町・楢葉町・富岡町・川内村・大熊町・双葉町・浪江町・葛尾村・飯舘村）は、県外から12市町村へ移住して起業する者に対象経費の3/4・最大400万円。募集要領の対象経費に**外注費、委託費（ホームページ作成委託費等）、広報費、研修費（事業主や従業員の研修）、パソコン等のリース・レンタル費**がある（パソコン等の購入費は「汎用性が高い物品」として対象外）。令和8年度の追加募集は2026-10-01〜10-23で、確認日には締め切られていた。subsidy_a.yml に入っていないので、県の制度として subsidy_a 担当に照合を頼みたい。
- 今申請できる（受付期間中・随時受付の）IT・HP・研修向けの町村の制度: 柳津町（後継者支援。受付期間の記載なし）、南会津町（経営拡大支援）、会津美里町（持続的経営発達支援）、大熊町（創業・本社機能移転、就労サポート。いずれも〜2027-01-29）、飯舘村（がんばる商工業者支援）。
