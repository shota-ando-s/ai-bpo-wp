  - 岩手県「滝沢市IPUイノベーションパーク運営計画2024」の立地・入居企業一覧（27社、令和6年3月時点）。https://www.pref.iwate.jp/_res/projects/default_project/_page_/001/078/145/ipukeikaku2024.pdf
  - WebSearch（担当上限12回のうち7回を使用）。
- 規模・所在地・事業内容は各社の公式サイトで確認した。名簿・houjin.goo の値は使っていない。WebFetch で読めないページ（Shift_JIS の文字化け、JavaScript で描画される会社概要、証明書エラー）は curl で公式サイトの HTML を直接取得して読んだ。証明書エラーで HTTP 取得した会社は JSON の notes に書いた。
- 公式サイトが開けなかった会社（DNSエラー・503・404・空応答）や、会社概要に所在地・規模がない会社は本表に入れず `_reference` に置いた。個人事業主・小規模なWeb制作者は網羅していない。
- 並べ順: 公式の従業員数の多い順 → 従業員数がない会社は資本金 → どちらもない会社は最後。
